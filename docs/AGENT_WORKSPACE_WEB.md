# Web 智能体工作区

版本：0.104.0-rc3。该改动复用现有 React / Runtime API，不修改冻结评测程序或实验契约。

`#agents` 为智能体库，提供搜索、来源筛选与紧凑列表 / 详情区。创建、导入、官方目录预览与安装、创建副本、导出、版本固定、启停、本地模型绑定、分享、同步冲突解决、版本历史与删除均保留；次要操作放在“更多操作”中。官方版本须先创建副本再起草候选。

`#agent-experiments` 为独立实验工作台。选择已安装定义后，左侧显示基线只读指令，右侧编辑候选指令。候选版本沿用既有 rc 递增规则。保存候选与准备免费验证分别调用 `rsi.candidate` / `rsi.prepare`，不会选择、安装或激活候选。最近实验来自真实 `rsi.list` 记录；登记状态不代表验证通过，当前接口没有更新时间或完整运行状态时不推断这些信息。运行与报告保留 `rsi.run` / `rsi.report`。所有摘要上传仍须每次明确输入单独批准的授权 ID，服务端核验其有效性；当前 Rust Web 没有独立授权撤销入口，不以本机隐藏按钮冒充服务器撤销。

实验备注保存在浏览器本机存储，以 origin / user / tenant 完整账号作用域隔离，并进一步按基线快照或实验 ID 区分。备注不进入定义、revision、实验 spec、执行证据或上传请求，也不参与评分与跨端同步。存储不可用时明确提示仅本页保留。切换账号立即清空旧编辑、结果与基线，迟到的旧账号操作结果不显示在新账号；未保存专业指令离开或换基线时提示确认。

独立 `/design-preview.html#agent-experiments` 只用于开发设计验收，页面内的明确假账号与公共文档夹具复用实际 `PluginRail` / `AgentLibrary` / `AgentRsiPanel` 组件。该入口不被生产 `index.html` 导入、不被生产构建列为入口；全部假请求由专用模块就地处理，未知操作拒绝，不向 Runtime、some.im 或模型转发。可用 `?lang=en` / `?lang=ja` 验证英文与日文。选择“文档整理助手 · 1.0.0”即可打开双栏，并验证候选保存、免费准备与报告。假记录不能作为实际模型质量或跨端同步证据。
