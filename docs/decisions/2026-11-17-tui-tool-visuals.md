# TUI 工具差异与当前命令

> 2026-11-19 更新：0.154.0-rc5 的[轮次收尾投影决策](2026-11-19-tui-turn-end-projection.md)把“轮次结束收回自动展开”扩展到已提交编辑差异，并收紧本地待发队列的记录绑定。以下保留原版本决策。

日期：2026-11-17。阶段：既有 Rust TUI 迭代。用户明确要求参考工具执行界面，展示实际编辑 diff，并只自动展开当前命令。

## 展示与状态

沿用 Ratatui/crossterm、full/compact 布局、终端字体及现有字号、间距、主题与圆角边界。编辑卡使用次要色文件头、黄色 hunk、绿色新增和红色删除，保留 `+`/`-` 及新旧行号，不单靠颜色表达。无差异或失败不虚构已修改内容；过长差异明确截断。新增提示走中、英、日 Language 资源，默认语言与 fallback 不变。

成功编辑后默认显示文件相对路径、增删行数、行号、差异及少量上下文，可点击收起。数据必须来自真实写入前后已绑定的内容和成功提交回执，不通过额外 shell、Git 或模型请求获取。预览、拒绝、回滚、失败不能画为成功修改。逐文件原子安装与外部写者边界不变。

完整命令复用既有脱敏 expansion；自动展开最近一条仍活动的前台命令，命令完成、失败或轮次结束即收回自动展开。并行请求以 tool call ID 匹配，不能按同名推断完成对象。用户手动展开的历史记录保留，手动收起优先于自动展示。只有公共摘要、缺少本机详细内容时继续显示摘要，不为显示追加查询。

## 数据与边界

Core 写工具生成有界 edit_display 回执（每文件 8 KiB、合计 64 KiB、32 文件，UTF-8 安全截断）；本地 Agent 事件和已有认证本机 Runtime SSE 原始事件投影到 TUI。默认 TUI 从公共 NDJSON 改接该本机 SSE，沿用游标重连、任务归属过滤和旧版轮询回落，不增加详情查询或新服务端端点。公共事件流剥除 edit_display 和完整命令 expansion，避免向 Web/手机广播源码及完整路径。显示再次脱敏并转义终端控制字符；脱敏须保留上下文标记、前导缩进、连续空格与换行，复用共享的保留排版入口，不能把源码按空白分词后重新拼接。原有通用脱敏 API 语义保持兼容。不将显示行号或折叠状态写进模型上下文、完成证据或持久协议。

展示状态独立模块管理，随记录删除、重排、清屏、会话切换重映射。折叠、搜索、阅读锚点和原文选区共用原有来源映射，显示不得改变执行、审批或取消语义。

## 验收

Rust 原生回归验证同名并发、乱序及重复完成、失败/取消、手动展开优先级、编辑差异颜色/行号/截断、窄屏和来源映射。Ruby 真实 PTY 使用私有目录与回环合成 Provider，验证 full/compact 的当前命令展开和结束收起、成功编辑差异及历史结束行；产出 Markdown/JSON，不调用真实模型或接触真实剪贴板。最终结果纳入整合验收，不以设计文档作为通过证据。
