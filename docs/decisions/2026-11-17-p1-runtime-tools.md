## 范围与默认约束

用户授权继续补齐剩余 P1。本轮工程默认如下；它们定义实施约束，不是已经通过验收的声明。

1. 语义重命名只由语言服务计算编辑集合，宿主把 WorkspaceEdit 转成已有多文件预览，再按一次性 ID 审批应用。语言服务不能直接写入。AST 首先提供结构化搜索，不自动改写。
2. 浏览器使用正式受控适配，隔离用户 profile；依赖明确配置，不下载或安装浏览器。只允许声明的来源和产物目录，副作用经过 Runtime 审批。不能用通用 MCP 包装声称已经强制执行导航或网络隔离。
3. 搜索后端独立于聊天 Provider，保留现有 some.im 兼容。配置、状态、未配置、认证失败、限流与空结果必须可辨认；密钥只经既有环境引用解析，不返回工具结果或诊断。
4. 项目模型策略约束每次实际发送，包括根会话、Worker、压缩、视觉、标题、判官、候选与回退。采用统一调用前门禁；缺省保持现有行为，启用策略后按明确允许集合失败关闭，不以提示词代替硬约束。
5. Goal 完成证据关联真实记录、执行身份、成功状态与代码快照。自由文本只作说明；人工观察明确单列，模型不能自称人工验收。重启后缺少可验证记录时不恢复为已核实。
6. LSP、AST、浏览器、搜索及 MCP 的配置、依赖、启用状态、权限原因和恢复建议随功能一并交付，复用 CLI/TUI/Web 的共享 Runtime，不另建执行状态或审批系统。状态查询不运行 Hooks、不刷新动态工具目录、不发起连接或读取 OAuth 凭据；未知认证保留为未知。doctor 同时判断依赖和配置有效性，只输出固定状态标签与恢复建议。

新增功能从 0.151.0-rc1 开始实现，rc2 保留首轮收口结果，最终恢复边界和队列整合采用 0.151.0-rc3，前后端、内部版本钉、安装元数据与文档保持一致。用户追加要求将原清单 P0/P1 全部闭环，并将并行会话的 TUI 改动一并整合、验收和提交；保留各阶段证据。安装、对外发布及合入默认分支另行执行，发布 tag 只指向已合入默认分支的提交。

## 验收边界

- 单元测试使用原生 Rust，网络使用本地合成服务，API/端到端验收优先 Ruby，并输出 Markdown 与 JSON。
- 语义重命名覆盖 UTF-16、跨文件、目标字符串键、无关同名字符串、重叠/越界/过期编辑、资源操作拒绝与取消；应用结果复用文件协议的恢复回执。
- 浏览器覆盖本地表单、路由、错误状态、快照/截图和业务断言，验证拒绝来源、隔离 profile、副作用审批和取消；缺少实际浏览器执行时明确标为未验证。
- 搜索覆盖独立后端真实 HTTP 请求、来源返回、未配置、认证失败、限流、空结果、响应预算与取消。
- 模型策略覆盖每类实际调用前拒绝、候选/切换不可绕过、端点与模型匹配、重定向边界；不能把 OS 网络沙箱与模型路由限制混为一谈。
- Goal 覆盖伪造、失败、跨身份、过期与重启丢失证据；同一次真实执行不能借自由文本洗成另一种来源。
- 最终运行相关回归、全工作区严格 Clippy、格式、版本一致性、源码篇幅和文档检查。真实模型评测、外部搜索计费、Windows 原生运行及外部发布不包含在本地合成验收中。

## 本轮实施契约

- `lsp.operation=rename_preview` 请求语言服务计算编辑，严格校验 WorkspaceEdit 后生成既有 `file_changes` 预览。未打开的目标必须在最终请求前建立并同步快照；不接受响应后才读取的文本作为编辑基线。版本化 `documentChanges` 必须匹配同步 URI 和版本。真实 TypeScript 服务 5.3.0 即使协商 `documentChanges` 仍固定返回 `changes`，因此仅为固定 TypeScript 客户端接受原生纯文本映射，以最终请求前的精确同步 URI、文本和 SHA-256 绑定，不伪造服务端版本；Rust 不开放该兼容路径，版本化响应仍拒绝缺失、null 和陈旧版本。混合形状、未知最终目标、别名、资源和注解整批拒绝。实际写入仍由 `file_changes.apply` 完成。
- `ast_grep` 首版为固定本地 `ast-grep` 可执行文件的结构查询和离线状态，不开放改写、自定义解析器或任意配置。缺依赖明确报告，不自动安装。
- `browser` 使用发行物内置的 Node/CDP 桥和用户明确配置的 Chrome 可执行文件，创建独立临时 profile，不附着日常浏览器。固定动作集合包含打开、快照、输入、点击、截图、声明式断言和关闭。点击与输入进入现有审批；来源检查不是宿主全进程网络隔离，不将导航控制冒充完整出站隔离。该路径不依赖 Playwright，普通 MCP 不持有此连接。
- `[search]` 首版支持 `auto`、`disabled`、`searxng`。`auto` 保留 some.im；显式后端失败不切换其他供应商。独立后端密钥仅支持环境变量引用，生产连接禁重定向并固定已核验地址；本地私网端点必须显式允许。
- 项目模型策略使用工作区内明确的策略文件，允许集合同时约束实际 Provider、模型和端点；每次发送前重新校验，辅助调用、重试、模型切换和回退保留同一项目归属。无策略的旧项目保持兼容，存在但不可读或非法的策略不得退回无限制。同进程按规范项目路径保留首次生效允许集，运行期重读只取交集；重建上下文和 Agent 修改项目文件不能扩权。可信宿主审查后扩大权限需重启所属 Runtime。
- Goal 的 `evidence_ref` 只能指向共享注册表生成的真实记录；文本 `evidence` 仅解释标准与证据的关系。成功状态、身份与当前代码快照须在勾选及完成判断时重新验证。旧文字不升级为执行证明，重启缺记录时失败关闭。

以上为已选实施接口；具体配置字段见 [Runtime 工具指南](../P1_RUNTIME_TOOLS.md)，当前交付状态、上游整合、实际执行及未覆盖范围见 [rc3 Markdown 验收](../verification/0.151.0-rc3/p0-p1-closeout.md)与 [JSON](../verification/0.151.0-rc3/p0-p1-closeout.json)；rc1、rc2 记录保留其历史语境。
