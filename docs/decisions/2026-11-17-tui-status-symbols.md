# TUI 消息状态符号与阅读提示

日期：2026-11-17。适用版本：0.152.0-rc4。既有终端界面的显示修正；沿用 Ratatui、现有字体与颜色、full/compact 布局、中英日语言范围。

用户要求减少「正在处理」「已完成」等重复过程文字。Runtime 身份绑定回执的消息前不再显示带方括号的状态短句，改用一个符号，颜色提供辅助区分；具体原因、需要人工操作的提示与队列管理说明继续本地化显示。尚未提交给 Runtime 的显式本地待发队列保留原有本地化前缀及淡出分类。

| 符号 | 含义 | 颜色 |
|---|---|---|
| ? | 提交尚未确认 | 黄 |
| ◇ | 已接收排队，尚未开始 | 灰 |
| ‖ | 主动暂缓 | 黄 |
| ▶ | 对应轮次已开始，包括等待审批或回答 | 青 |
| ✓ | 对应轮次正常结束 | 绿 |
| ◒ | 部分完成 | 黄 |
| ✗ | 失败 | 红 |
| ■ | 中断 | 暗灰 |
| × | 取消 | 暗灰 |

这些符号来自既有 Turn/request 身份绑定的回执与真实终态；不按文本猜测状态，不修改 Runtime 调度、审批、消息顺序或持久协议。`✓` 只代表该轮次正常结束，不证明所有历史任务或 Goal 已完成。未确认提交不提前显示接受或成功符号。优先与独立处理标记继续保留其原有含义。

普通完成后的活动区与底栏也复用 `✓`，不重复显示「本轮已完成」；无具体阶段时仅保留既有动画与耗时，不补泛化的「正在处理」。具体阶段、非正常结果及人工等待仍保留说明。

消息徽标保持静态。`Started` 同时涵盖等待人工输入，持续旋转会误导用户认为模型仍在运行；当前活动区继续使用既有动画与具体阶段，不在历史消息上追加动画、计时器、模型请求或工具调用。

符号颜色仅应用到已绑定回执的装饰单元格，不识别或改色用户正文里的相同符号。保持消息块背景、窄屏换行、来源锚点、原始时间和选区坐标；复制正文不带徽标、状态文字、时间或布局填充。

回看提示使用正文之外的现有分隔线：full 为聊天框底边，compact 为输入框顶边。先清空提示区域，避免短提示或宽字符与旧边框混字；不新增正文行、不缩小视口。点击或拖选仍在鼠标按下时暂停自动跟随，保留增量到达前的选区稳定性，但不能把「返回最新」提示覆盖到首答耗时、总耗时、tokens 或正文上。原记录不改写；点击返回最新不发送草稿。

验收使用原生回归及私有 HOME/工作区、回环合成 Provider 的真实 PTY，覆盖 full/compact、窄屏、鼠标按下/拖选/松开、窗口缩放、原文复制和真实状态转换。结果单独记录，不沿用旧版固定应用的通过结论。
