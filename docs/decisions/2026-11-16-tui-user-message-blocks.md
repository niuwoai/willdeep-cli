# TUI 用户消息的角色与排版

适用版本：0.149.0-rc7。既有 TUI 的显示修复，沿用中、英、日语言范围及现有字体、字号与终端角色配色。

## 角色语义

`You:` 表示用户输入，显示发送时间，不显示模型名。助手消息按该条回复记录的模型显示，不使用当前会话模型回填旧回复。即使旧用户行已有模型元数据，显示层也必须忽略。

## 最小显示规范

- 用户消息块整体靠右，块内正文左对齐；助手和工具行保持左侧布局。
- 用户块背景 token 为 `RGB(36, 48, 62)`，正文沿用青色角色色，时间沿用灰色。搜索命中的黄色背景优先于消息背景。
- 可用宽度达到 20 列时，消息块最大宽度约为聊天区的 80%，上限 100 列，左右各留 1 列内边距；短消息按内容收窄。更窄时使用全部宽度并取消内边距，优先保证内容可读。
- 用户消息前后至少一行空白；同一助手回复内的工具与思考保持紧凑。`/spacing` 继续在基础间距上增加额外空行。
- 最后一条用户消息之后暂不填尾部空行；流式输出出现时补角色间距。等待动画与压缩状态仍紧贴该消息块下方，状态不写进历史。
- 不增加上下内边距，消息正文、附件、折叠按钮按同一内容宽度换行；背景和左右缩进在换行、折叠和时间标签之后统一应用。

## 坐标与验收

水平缩进以显式显示空白参与选择坐标，原始消息不改写。纵向行号由统一渲染结果生成，保持附件、折叠、搜索、代码复制和滚动命中一致。缓存仍按聊天区宽度、行距、显示名、搜索与消息时间更新。

验收覆盖：新消息与历史用户消息无模型标记；助手切模型后旧回复归属不变；宽窄屏和中英文换行不越界；完整/简洁布局显示背景及右对齐；用户与已完成/流式回复之间有间距；折叠、附件、搜索、选择、等待动画、压缩状态和代码块位置不偏移。
