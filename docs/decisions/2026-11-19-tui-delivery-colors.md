# TUI 用户消息的送达颜色与待发提示

> 2026-11-19 更新：0.154.0-rc5 的[轮次收尾投影决策](2026-11-19-tui-turn-end-projection.md)收紧了本地待发队列的记录绑定：只认仍是其未改写占位行的记录，切换会话清空旧行号。以下保留原版本决策。

日期：2026-11-19。适用版本：0.154.0-rc4。既有 TUI 显示修正，沿用 Ratatui、中英日、full/compact 布局及蓝灰用户消息块。

按用户指定，移除已开始的三角图标，以颜色区分已发与队列中待发。排队与暂缓也不再额外显示非终态装饰符号。已发消息正文沿用 Cyan，真实待发正文使用 Yellow；正常完成保留 Green 的 `✓`。提交未确认的 `?` 与部分完成、失败、中断、取消回执仍显示，不把待发或请求超时推断为已开始、成功或取消。

真实待发消息下方另起次级提示行，中文为“Ctrl+Q 管理待发队列”，英文与日文通过既有 `Language::text` 提供。终端没有逐行字号能力，使用 Gray + DIM 表达次级信息，不改变系统字体。提示按消息内容宽度换行，置于正文、附件、折叠控件及时间之后，不占正文八行预览额度。消息开始或结束后撤除提示、恢复已发正文色；绿色对勾只说明该 Turn 正常结束。

待发集合来自 `delivery_echo` 中精确记录绑定的 Queued/Held，或显式本地队列的 `transcript_row`；Unconfirmed 不证明已进入可管理队列。真实状态绑定身份，不检查用户正文中的图标或“待发”字样。优先/独立处理标签、主动暂缓不会自动发送的反馈保持有效。内部本地队列前缀继续用于原有记账和淡出分类，渲染与复制使用其真实正文。

`user_message` 将记录身份映射至折叠位置，`message_time` 渲染正文色并追加不可复制的 Decoration 提示。提示不进入模型上下文、用户原文、附件或命中控件；时间、附件、折叠与来源坐标继续对齐。待发集合参与缓存键，Queued → Started 即使记录字符串完全相同也刷新样式及高度。视口的本地队列来源同样使用真实正文，保持阅读锚点和选区。

验收使用 Rust 原生回归及私有 HOME/WILLDEEP_HOME/工作区、回环合成 Provider 的真实 PTY，不连接真实模型或用户 Runtime，不写系统剪贴板。覆盖状态转换、同文不同身份、晚到快照、未确认边界、中英日、窄屏、附件、折叠、原文复制与完成绿勾。版本检查与验收记录单独保存；本次未要求安装或公开发布。
