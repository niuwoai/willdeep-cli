## 固定实验条件

- 模型仍为 `some-im / deepseek-v4-flash`，不换模型，不升级，不调用优化器、摘要器或 LLM 裁判。
- 原 suite、baseline、candidate 的 hash 保持原提案值；唯一候选改动是要求最小复现。工具与原生系统词保持各端正常 Worker 行为，不因输出评分改写系统提示。
- 请求固定非流式、temperature=0、输出最多 4000。每 attempt 最多四请求、总 token 16000、墙钟 120 秒；root 串行调度两端。请求前以 UTF-8 字节加 framing 余量保守预留输入 token，按剩余额度降低输出上限；不能预留则拒绝发出。
- 套件 24 题、双臂、3 重复、Rust/Mac 共 288 次；额外基础设施 attempt 上限72，单 trial最多重试一次，holdout额外上限18、访问总上限90。访问/请求在执行前持久化，不因中断返还。
- AB/BA 交错顺序预先固定。每次使用随机目录，模型只收到 fixture.txt、共同题目 prompt、实际定义及正常原生工具；不提供 task_id、缺陷标签、oracle、其他试次或评分。
- 前两 split 全部计划样本有完整可核对证据后才开 holdout；质量失败照实保留且不重试、不阻止后续采样。该采样规则与 mock 工程门禁的“全部测试通过”晋升规则分开，避免只完成容易样本。未知消费或关键执行证据缺失暂停全批。
- 模型目录中 supports_tools=false 为未验证目录声明。现有 Mac 实现已记录此字段对已成功调用工具的模型不可靠，不据此换模型或伪造 read。第一正式 trial 的实际工具事件才是工具可用性的证据，不增加额外付费探测。
- 路由映射、两端二进制、宿主评分器、控制器、预算代理及本记录的哈希在首个付费请求前冻结。真实 X-Routed-Model 和响应 model 原样保留，逻辑批准模型另用 broker 回执区分；路由变化即停。

## 宿主评分 v1

共同 Ruby 评分器只读模型原始最终正文，不读宿主附加报告作答案。不改变各端正常报告系统词，允许 JSON 外有固定报告段落或 Markdown 包裹；必须只有一个完整 JSON 对象。多个对象、重复键、非法对象均失败。

对象只能包含 `has_defect`、`line`、`reason` 三字段。has_defect 为布尔；reason 为非空字符串；有缺陷时 line 为正整数，无缺陷时为 null。分别记录：

1. `schema_valid`：满足上述格式。
2. `classification_correct`：缺陷/无缺陷分类符合冻结 oracle。
3. `localization_correct`：分类正确且行号等于冻结的缺陷根因行。
4. `read_observed`：真实原生文件工具成功读取本题 fixture，并进入后续模型请求，不能由模型自称完成。
5. `fixture_unchanged`：执行前后内容相同。

`passed` 为上述条件全满足。主要比较分类准确率，精确行、输出格式、文件读取和完整通过率分别报告；相关行与根因行可能有合理分歧，因此精确行不是完整代码审查质量。reason/最小复现的语义正确性不由这套规则评判，不声称证明复现能力提高。截断/预算耗尽、基础设施错误、未知消费、未执行不伪装为普通模型正确/错误分数。

每个 attempt 保存原始答案、实际加载 revision、请求与回执、实际 route、真实 usage、根/Worker 血缘、工具事件、宿主 verifier 输入哈希。无改进也照实报告，不自动晋升、不推送官方定义、不上传生产 RSI，不发布客户端或生产服务。

## 预算可信边界

只有根控制器持有真实推理凭据；原生子端只持有当前 trial 的短期能力令牌。代理拒绝过期能力、重复请求、并行请求、其他模型/参数及超额预留。JSON 中的批准字段不产生令牌，免费 RSI API 的付费拒绝策略继续生效。

未知用量和在途费用保留最坏预留额并暂停，不当零、不盲重放。HTTP 错误若无法核实是否扣费也暂停，不能为凑满题量使用额外重试。最终报告分别给出实际 token、按冻结最高费率保守核算、账单已核实金额及未解决的费用暴露。
