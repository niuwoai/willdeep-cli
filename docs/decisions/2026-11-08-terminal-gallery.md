# 终端图片列

日期：2026-11-08。版本：0.147.0-rc11。

## 背景

TUI 的草稿附件之前只能在自己的附件面板里看。在 MuseTerm 里运行时，粘贴板上的图片属于终端进程，willdeep 自己读不到：走 SSH 时它的进程在远程，即使本机运行，它拿到的也是另一份粘贴板。

## 决定

由 MuseTerm 绘制缩略图并读粘贴板，willdeep 保留附件的所有权。两边用私有序列 OSC 7771 对话，帧以 BEL（0x07）结束：

```text
ESC ] 7771 ; v=1 ; <op> ; <字段，以 ; 分隔> BEL
```

- willdeep 启动时先把一根管道接到标准输入前面，再写 `hello`。终端没见过 `hello` 不会把图片字节写进来，所以没装过滤的程序收不到这些字节。
- 过滤拿掉 `drop` 和 `delete`，其余字节原样交给按键解析。crossterm 会把 `ESC ]` 变成 Alt+]，所以必须在它之前拿掉。
- 草稿里的图片附件变化时写 `list`（JSON 数组，只有 id、名称和是否可删，不带像素）。空列表让终端收起列。
- 收到 `drop` 后解码 PNG，成功则先加入草稿再回 `ack`（`<nonce>;<id>`），失败回 `reject`。收到 `delete` 后删掉对应草稿附件，再回 `remove` 并重新报列表。

已发送的附件不进列表：列上的删除图标只对草稿有意义。

## 限制

只收 PNG，解码后不超过 8 MB，与草稿附件的 12 个、10 MiB 上限一起截断。一帧超过 120,000 字节还没有终止符就放弃，不会一直吞掉后面的按键。
