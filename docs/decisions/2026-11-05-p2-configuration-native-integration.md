日期：2026-11-05。状态：开发工作树整合；组合测试待执行，未公开发布。

## 目的与来源

在完整子会话 P2 的 `ca44885b` 工作树增量整合 `ca44885b..f2094c07` 的 rc8 修复、基于 `f2094c07` 的聊天配置 rc9 与原生夹具 rc9 补丁。使用共同祖先逐项合并，保留当前 P2 未提交实现，不把另一来源整文件覆盖到重叠模块。元数据统一 `0.145.0-rc1`；旧版本与历史证据保持原身份。

## 三个功能边界

| 模块 | 保持的职责 | 不扩大的权限/事实 |
|---|---|---|
| 完整子会话 P2 | 接管/脱离、结果订阅、依赖、schema 2、家族容量、实际槽准入、失败收敛、checkpoint/通知一致性 | 聊天仍以 Core SessionStore 为准，不递归派生，不自动合并 worktree；接管/脱离不扩大原只读上限或重置家族预算 |
| 聊天压缩配置 | 默认父 Harness 的受控 schema/snapshot/plan/apply，复用现有 Ruby 服务与全局审批 | 仅 `[agent] compressor_model`、`compressor_profile`、`compressor_context_window`；Worker、委派子会话、受限 MCP 任务不获得全局配置工具 |
| 原生测试夹具 | 每测试私有映像、客户端 ChildGuard、按精确临时 home 正常停止、期限内定向回收与进程退出验证 | 仅测试生命周期，不改产品启动、停止、Provider、调度或取消期限，不干扰其他 home 与保留中的预览 |

rc8 的无变化账本免提交与 P2 的控制锁/显式持久化屏障共同保留。首答在本次首个正文增量到达时记录，提交事件头与 Turn/Task 防止旧输出污染；准备链路诊断默认关闭，不输出配置或消息。

## 配置契约与刷新

目标绑定实际加载文件，遵守 `--config`、`WILLDEEP_HOME` 和符号链接解析。预览经 Rust 解析、Runtime 语义与压缩 Provider 构建校验，宿主计划绑定本实例、edits 和文件 SHA256 revision；保存只接受 plan_id，目标锁内检查 revision，备份目录另加锁，原子替换并写后校验。不返回原 TOML、注释、凭据预览或私有候选；回执未知不自动重放。

只读可预览不可保存；strict/smart/workspace-write 保存需现有全局审批，full-access 沿用已有授权。P2 接管/脱离不自动赋予配置能力，委派来源与能力上限继续保留。

下一次新 Runtime Turn 在实际开始执行时重读配置，当前 Turn 保持快照。空闲 TUI `/compress` 先加载与构建、再取得会话执行权、整体替换候选与窗口；一次压缩保持同一快照，错误经安全本地化反馈后继续交互。`/local` 其余配置仍为启动快照，成功刷新后的压缩设置在摘要失败/取消后也不回退。
