# TUI 轮次收尾后的工具投影与本地队列绑定

日期：2026-11-19。适用版本：0.154.0-rc5。既有 Rust TUI 显示修正，沿用 Ratatui、中英日、full/compact 布局与现有工具差异样式。

用户要求：轮次已经得到最终结果时，不再展示中间过程的 diff。工具行的自动展开因此只属于进行中的轮次：轮次进入终态后，已提交编辑的差异自动折叠，只保留一行工具回执；用户手动点开的差异不受自动折叠影响，轮次收尾后仍保持展开，点击仍可重新打开。真实回执、差异颜色、行号、截断、脱敏和 `/tools` 展开语义不变，不删除记录、不改变执行、审批、取消或持久化协议。

自动投影只来自成功的写入回执；预览、拒绝、失败和取消不借收尾规则伪造差异。轮次结束的判定使用既有的 `running` 状态，命令的当前展开原本就在完成或轮次结束时收回，本次把同一生命周期规则扩展到编辑差异。渲染缓存加入运行态，收尾后不复用收尾前的展开帧；用户展开的行仍以独立状态参与缓存。

本地待发队列的记录绑定同时收紧：一个待发项只拥有仍是其未改写占位行（`You: ［待发］ …`）的记录。切换会话时记录整体替换，旧行号必须清空；发送失败后记录会被改写成未确认回执 `You: ? …`，此时不得再用本地队列正文替换显示或复制。未确认回执保留 `?` 与真实正文，来源坐标按实际前缀剥除，整段复制不丢首字符。颜色与 Ctrl+Q 提示只给仍由真实身份绑定的待发记录，未确认状态不冒充已进入可管理队列。

验收使用 Rust 原生回归覆盖：轮次中差异展开、收尾自动折叠、点击重开、手动展开跨收尾保持、切换会话不串记录、失败回执前缀与完整复制、编辑保存后的缓存刷新；真实 PTY 验证运行中、收尾与点击重开，不连接真实模型或用户 Runtime，不写系统剪贴板。版本、CHANGELOG、产品概览与架构文档同步；候选未安装、未公开发布、未打 tag。
