# TUI 执行反馈、消息送达与阅读位置

日期：2026-11-17。用户已确认实施前三项终端体验改进；这是既有 Rust TUI 的功能迭代。开始核查时基线为当前 worktree 的 `0.150.0-rc3` 及已有未提交改动；并行开发已统一进入 `0.151.0-rc1`，本轮在该待验收版本内追加 TUI 功能与验证记录，保留其他会话改动。安装、提交和发布另行决定。

## 范围

1. 执行反馈清楚表达当前真实活动与人工等待；短暂活动可替换，有价值的模型阶段说明保留在时间线上。
2. 区分客户端草稿、提交中、已接受排队、主动暂缓、开始处理与提交失败；优先发送的文案与 Runtime / 本地执行实际语义一致。
3. 流式增量、历史加载、展开折叠和窗口重排期间保留阅读位置及选择的原文；回看时提示有新内容，并提供回到最新的入口。

本轮不实现 `/btw`、LSP 安装提示、全新 Runtime 队列或新协议；复用既有持久队列、事件与审批边界。其他会话的编码工具和审批 Hook 修改完整保留。

## 显示与交互约束

- 保留 Ratatui/crossterm、终端字体、现有主题及 full/compact 两种布局；不新增 UI 框架。
- 普通正文使用现有正文色，活动、条数和操作提示使用现有次要文字色，等待和失败沿用现有强调/错误语义；同时提供文字，不能只靠颜色区分。
- 新状态和提示经既有中、英、日 `Language::text` 入口；默认语言与 fallback 不变，无新增 RTL 范围。
- 执行反馈来自实际事件和可验证状态，不以工具名称猜测测试通过、修改成功或剩余进度，不显示虚构百分比。
- 人工审批/提问优先于普通工具和模型等待；现有弹层键鼠优先级、双 Esc 中断和草稿保护不变。
- 队列由 Runtime 返回的身份和状态决定。提交成功只表示系统接受，不能表示模型已读取；同正文的不同消息不得按文字合并。
- 已开始处理的队列项不可过期编辑。失败保留可恢复的原文和附件，不能静默重新提交。
- Runtime 优先发送可能请求停止当前轮次；本地模式的插话沿用独立语义。文案必须明确其真实影响。
- 回看、拖选和输入草稿编辑期间，后台执行继续接收并保存更新；不得通过丢弃增量或暂停整个 Runtime 来固定画面。
- 选择复制保持原文边界，布局留白不进入剪贴板；SSH 沿用 OSC 52，验收不得写真实系统剪贴板。
- 历史轮次结束分隔线紧接上一轮回复及其时间/模型标注，不插入基础或配置行距；下一轮用户消息前仍保留原间距。仅整段聊天末尾的当前分隔线显示一次等待输入提示，单条记录渲染不得自行补提示；旧记录的中英日提示按显示投影移除，不改写原会话。
- 新逻辑和测试拆分独立模块，不继续扩大接近 3000 行的主文件。

## 状态来源

`TurnStarted` 只表示模型步骤开始准备，可能随后压缩上下文，不能据此宣称模型已经回复或推理。Core 在完成请求准备、取得 Provider、即将进入主请求时发出 `ModelRequestStarted`；既有 Runtime 事件通道以 `model_request_started` 投影该边界。它只证明开始等待模型，不证明模型已读取、生成成功或任务完成。没有该事件的旧 Runtime 继续保留最后一个可验证阶段。

队列使用既有提交回执和轮次查询核实身份与状态，不新增队列命令或改变 Runtime 调度协议。回执丢失时保留 request 身份并后台对账，暂缓消息没有开始事件也能核实；开始事件先到的记录只在轮次身份确认后合并。空闲提交失败恢复完整编辑器、原始命令、光标和展开状态；本地队列派发始终归还独立草稿，失败消息只留队列，成功时原待发记录直接绑定回执。调用入口不得覆盖真实终态反馈。重连快照恢复运行态时绑定实际 task/turn 身份，旧任务终态不能结束新活动。

0.151.0-rc3 修正队列时间线：入队反馈只投影到身份绑定的消息状态和临时状态区，不追加永久系统回执；本地插话未赶上时也复用状态区。Runtime 首次有序 `queued_user_message` 事件先结清旧思考、回复与定稿缓冲，再移动该消息到上一轮完整输出之后。轮次状态与是否已正式落位分别记录，快照提前推进、重复事件与清屏墓碑不能造成再次移动或复活。丢回执后合并到已落位记录，迁移原提交时间、附件及来源锚点；移动同步索引、缓存、搜索和选区，排序不使用提交时间。

排版来源映射只属于 TUI 显示状态，不进入模型上下文。输入草稿、聊天选区和代码块复用同一剪贴板路由，本机成功与向终端发送 OSC 52 分别反馈。OSC 52 没有写入回执，不能据此声称终端已完成实际剪贴板写入。

## 验收

Rust 单元测试覆盖真实状态优先级、阶段说明去重和保留、提交与排队/暂缓区别、优先发送文案、开始后的队列投影、失败恢复、阅读锚点、软折行/Unicode、展开折叠、窗口宽度变化及选择稳定性。相关旧测试必须回归。

真实终端验收使用 Ruby、私有临时 HOME/WILLDEEP_HOME/工作区、回环假 Provider 和独立 PTY；验证 full/compact 布局下执行反馈、忙时补充消息、回看期间的新输出、返回最新位置及草稿保留。输出 JSON 与 Markdown，明确任何未覆盖边界；不调用真实模型、不使用真实凭据、不操作已有 daemon 或真实剪贴板。

实现和最终结果随本轮代码同步更新产品概览、TUI 指南、架构说明、版本元数据与 CHANGELOG。

2026-11-17 本地验收已通过：636 项去重原生测试、full/compact 交互共 18 项真实 PTY 检查和输入草稿回归 14 项。两项手工性能测试未执行；真实模型、跨平台 CI 与外部终端剪贴板写入不在本轮验证内。失败尝试、修正和剪贴板隔离偏差见[验收记录](../verification/0.151.0-rc1/tui-interactions.md)。尚未提交、安装或发布。
