# Claude Code 终端体验观察

记录日期：2026-11-17。依据为用户提供的终端截图和用户补充观察；本记录用于体验对照，不代表对所有版本、平台和插件配置的完整能力核实。

## 截图中的体验优点

- 用户输入通过底色与提示符突出，方便回看需求。
- 需求、阶段说明、工具调用和发现沿同一时间线展开。
- 耗时、搜索次数和工具次数以简短摘要展示，减少过程信息的干扰。
- 长任务提供有内容的阶段说明，帮助用户理解进展。
- 执行过程中仍可输入补充指令，并进入待发队列。
- 待发消息可以编辑，也有立即发送入口。
- 当前执行状态、模式和中断入口保持可见。
- 快捷键提示靠近对应操作，降低记忆成本。

## 用户补充：按需提示安装语言服务

用户观察到：在必要时，Claude Code 会主动弹出提示，要求安装 TypeScript、Rust 等语言对应的 LSP Server。

值得借鉴的是在语言能力真正需要时识别环境缺口，并把安装入口放在当前工作流程里，说明所需组件和用途，让用户当场决定是否安装。需要分别看待语言服务能力与依赖安装引导，已支持 LSP 不等于已经有按需安装体验。

本项先作为产品体验记录。本轮开发范围仍为 TUI 输入区草稿的选择与复制，未包含 LSP Server 的安装提示实现。
