# 四端会话协作与移动审阅实施计划

> 日期：2026-10-20
> 状态：历史实施计划。Rust 发布候选为 0.110.0-rc2；当前验收见 verification/0.110.0-rc2/README.md。Mac 与 Android 独立仓库不随本次 Rust 发布。历史记录中的未完项以末尾最终验收为准。

## 目标与边界

使同项目的独立会话能够发现彼此、发送协调消息、在执行边界处理消息并回报结果；四端都能辨认来源、查看状态、回复和跳转。
Android 是远程控制面，必须分别验证 macOS 宿主和 Rust Runtime 宿主，不在手机复制执行引擎。
同一会话的多端同步与独立会话协作分别建模，手机重新连接不得重复启动任务。
本轮实现每种宿主内部的多会话协作及其手机入口。Mac 与 Rust 宿主直接互投、跨设备联邦列为后续阶段，必须先解决身份认证、项目映射和设备寻址；不能宣称本轮已经完成跨宿主协作。

- 每个交付面实施前重新核实最新基线接口，旧调查结果不替代当前证据。
