## 问题与修复

Harness 构建无条件恢复团队；旧会话有排队、运行或未投递结果时，即便只是打开 TUI，也会占用团队锁或中断旧记录，与 Runtime 执行冲突。

团队恢复现在位于取得会话执行权后的执行入口，每个 Agent 执行器只恢复一次；认领失败允许稍后重试。团队控制 Turn 不调用父模型，因此单独保留恢复入口。
