# 详情弹窗鼠标关闭验收

日期：2026-10-20。开发版本：0.108.0-rc2。

- Inbox、后台任务、Agent、Worktree 详情和帮助弹窗原有的 Esc 关闭提示支持左键点击，使用下划线标识；不增加弹窗行高或调整密集列表。
- 命中区域按终端字符宽度计算。标题在窄屏放不下时显示紧凑 `[Esc]`，重绘标题区域避免截断中文宽字符。
- 点击仅关闭当前顶层面板，复用原关闭逻辑，不触发下层动作。审批/提问遮挡时，底层关闭按钮不可点击；运行任务、草稿和 Inbox 条目本身保持不变。
- 源码版本、内部依赖、Web 元数据及变更记录同步。当前 Changelog 接近 3000 行上限，将最旧的 rc63 段原样移动到已有历史文件，并核验内容无损。

验证结果：TUI 全部 257 项通过（含弹层关闭 11 项）；严格 Clippy、格式、diff 空白与源码行数检查通过；工作区版本一致性检查通过。

真实终端：`ruby scripts/overlay_close_tui_verify.rb <开发二进制绝对路径>` 在隔离 home 中启动 TUI，输入未发送草稿，按 F1 打开帮助，再以鼠标点击原 Esc 提示；用仓库已有的 xterm 模拟器还原最终屏幕，确认帮助关闭、完整草稿仍在、未提交消息或创建会话。通过结果见 [tui-report.json](tui-report.json)，原始 ANSI、还原屏幕和 JSON/Markdown 报告由脚本保存在其输出的临时目录。

Inbox 另通过实际渲染与点击命中测试覆盖中英日文、正常及窄屏、按钮边缘、相邻空白、运行状态和草稿保留。未操作用户真实 Runtime 或任务。
