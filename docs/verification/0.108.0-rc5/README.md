# Job 取消、只读自动派工与 root 本轮计时

日期：2026-10-20。版本：0.108.0-rc5。

- 完全访问模式取消当前 Harness/会话持有的 Job 免审批，并记录原有审批审计。脱离 Job 必须有明确会话 owner 且元数据 ID 一致；其他会话、无主 Job、其他权限模式保留审批。Job 查询拒绝路径穿越和元数据 ID 冒用。
- Rust 配置、Harness 与共享 Runtime 参数的只读自动派工默认值统一为 true。显式 false 保留，关闭路由时不派工。只自动执行高置信度只读预检，写入类任务继续走原任务包、验收和权限边界。
- root 的 TUI 侧栏、详情及 Web 时长按 Agent 当前 task_id 对应的 started_at/completed_at 计算，Agent 原始 created_at 不变。缺失任务时间明确提示未知，不回退到生命周期；子 Agent 保留自己的执行时长。

回归用例：完全访问取消自己的进程内 Job 无审批；脱离 Job 跨会话、无主记录及其他档位仍审批；隔离 Runtime 实际启动并取消自己的后台命令无审批记录；默认配置实际生成 scout 子 Agent、读取夹具、向父模型传回 worker-report，夹具不变；root 创建于 116 小时前而本轮 45 秒时，终端渲染与详情显示本轮 45 秒；连续两轮、排队、旧记录和子 Agent 计时隔离；Web 摘要同样使用本轮时间。

所有联调使用临时 home、工作区和 mock Provider，不取消用户原任务，不重放插话。发布与 Runtime 交接前另行保存私有备份，核验原会话历史、任务状态与插话份数；既有 TUI 窗口保留以保护进程内草稿和队列。

本地最终结果：CLI 780 项通过、1 项既有忽略；Core 790 项通过、6 项既有忽略；Runtime 集成 36 项通过；脱离进程集成 18 项通过、1 项既有忽略；SDK 客户端 7 项、协议 37 项、Core doctest 3 项、协议 doctest 1 项及内部版本一致性通过。严格工作区 Clippy、Web build/lint、格式、diff 空白及源码大小检查通过。旧显式关闭派工配置继续匹配原跨端指纹向量，默认开启不改写已有显式参数。
