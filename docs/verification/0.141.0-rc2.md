# 0.141.0-rc2 补充验收

日期：2026-11-04。类型：发布前补充验收快照；最终发行状态以 [GitHub Releases](https://github.com/niuwoai/willdeep-cli/releases) 为准。

## 修复依据与范围

[v0.141.0-rc1 的发行流水线](https://github.com/niuwoai/willdeep-cli/actions/runs/41745863265) 中，Windows workspace 测试成功，但 `Verify release / test (windows-latest)` 的 Clippy 在 `crates/willdeep-core/src/workflow/store/io.rs:12` 报 `unused_mut`，因 `-D warnings` 失败。macOS universal、Linux amd64/arm64、Windows x64 四项二进制构建成功，发行门禁仍跳过 GitHub Release 和 npm 发布。原 tag 保留，修复递增到 rc2。

产品代码差异仅一行：目录构建器显式调用 `recursive(false)`。该方法在所有平台需要可变引用，消除 Windows 上仅因 Unix 条件编译而未使用可变绑定的问题；值与标准库默认值相同。Unix `0700`、非递归创建、AlreadyExists 分支、真实目录检查、符号链接拒绝和错误上下文保持原行为。没有增加 lint 豁免。

版本同步覆盖 Cargo workspace、两处 runtime 内部依赖版本钉、Cargo.lock 四个本地包、Web/npm、安装清单及当前产品/契约文档。Cargo 自动更新锁文件，未升级外部依赖。
