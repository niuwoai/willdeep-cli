# 0.143.0-rc6 发行配置验证

本记录是 rc6 提交前的验证快照，后续公开发行和三机安装需另外核验。

## 原因与范围

rc5 Release run [41875495989](https://github.com/niuwoai/willdeep-cli/actions/runs/41875495989) 的两次尝试中，macOS universal 均未获得 runner，`steps=[]`；annotation 为 `The job was not acquired by Runner of type hosted even after multiple attempts`，并明确提示 macOS arm64 runner 容量限制。其余九项作业两次均成功，包括 Windows/Linux/macOS 测试与 Clippy。GitHub Release 和 npm 发布因依赖未满足而跳过，rc5 标签保持原指向。

rc6 将 macOS 发行构建固定到官方标准 `macos-26-intel` runner，两个 Apple Darwin 编译目标与 `lipo` 合并继续保留，并验证归档前的 Mach-O 包含 x86_64、arm64。发布前新增 tag 与版本元数据一致性检查，不改产品运行代码。

官方依据：[runner-images 可用镜像](https://github.com/actions/runner-images#available-images)、[标准 runner 清单](https://github.com/github/docs/blob/main/data/reusables/actions/supported-github-runners.md)、[Rust 1.94.1 Apple Darwin 支持](https://github.com/rust-lang/rust/blob/1.94.1/src/doc/rustc/src/platform-support/apple-darwin.md)。切换池不保证 Intel runner 永远有容量，实际双架构构建结果仍以本次 CI 为准。

## 本机已执行

- Web TypeScript 与生产构建通过；仍有既有的大 bundle 提示。
- npm 安装契约测试：6 项、37 个断言，0 失败、0 错误。首次命令设置 Ruby 内部 UTF-8 编码导致二进制夹具写入转换错误；使用项目原有内部编码设置重跑后通过，未修改测试或安装器。
- `cargo metadata --locked --no-deps --offline` 验证四个工作区包均为 `0.143.0-rc6`；两个内部 runtime 版本钉、Web/npm 清单、产品与架构头一致。
- 发行版本守卫正确接受 rc6，拒绝旧 rc5 和非法版本参数；检查覆盖 Cargo/lock、Web/npm、安装清单 tag、产品/架构版本头与 CHANGELOG。
- 工作流 YAML 可解析，runner 与 universal 构建、架构检查、发布门禁配置符合目标；`git diff --check` 通过。
