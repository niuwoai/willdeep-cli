# 0.108.0-rc6 发布验收

日期：2026-10-20。

本版包含长会话流式渲染性能修复、Chat Completions 思考内容首片及时显示，以及按版本方向区分客户端和 Runtime 的更新提示。Rust 内部依赖、Web 和产品说明版本一致。

## 本地验证

- 完整 Rust 工作区串行测试：CLI 783 通过、3 忽略；Core 791 通过、6 忽略；后台 Job 集成 18 通过、1 忽略；Runtime 集成 36 通过。
- 工作区版本依赖检查 1 通过；Provider 契约 3 通过；Runtime Client 7 通过；Runtime Protocol 37 通过；工作区文档测试通过。
- `cargo clippy --workspace --all-targets -- -D warnings` 通过。
- Web 构建、lint、23 个文件的 153 项测试通过。
- 格式、diff 与手写源文件 3000 行边界检查通过；最旧一段 Changelog 原文归档，无记录丢失。
- 优化版的渲染一致性与性能测试 4 项通过；详细数据见 [流式性能报告](streaming-performance.md) 与 [原始 JSON](streaming-performance.json)。2000 条历史三次平均单帧耗时从 53.59ms 降至 0.80ms，定速输入显示延迟 P95 为 1.80–4.68ms。

首次并行完整 CLI 测试在既有 RSI 文件锁用例的释放后立即重开断言上失败（其余 782 项通过）。该用例精确单独复测通过，随后完整工作区以 `--test-threads=1` 串行复测全部通过；未修改或跳过该锁用例。发布流水线还会按原有并行设置执行多平台完整验证。

## 交付验证约束

- 通过 PR 保留修复和发布验收两条提交，集成到 develop 后快进 main，不改写共享分支。
- 标签触发多平台发布，核对四个平台发行包；macOS 必须包含 arm64 与 x86_64。
- 从实际发行包提取 Favorites，验证其版本至少为 2.3.0、富文本服务文件和 MCP initialize 版本。
- 分别读取 Cargo、Homebrew、Runtime 与 Runtime 所有 Web 服务的版本，不能把安装成功当成运行进程已更新。
- 原会话和 Runtime 账本在私有目录备份，待原任务正常完成、无待审批和待回答项后安全交接。升级后核对历史消息、原插话唯一性、任务终态、Agent 身份及 Job 元数据。
- 用户现有 TUI 不强制关闭，避免丢失进程内草稿或队列；重开客户端后加载新版。不会向用户原会话插入测试消息。
- 安装后使用隔离 home、workspace 与本地 SSE 模拟源验证真实二进制的完整正文增量和思考首片，不请求付费模型。

最终 GitHub Release、安装版本、Runtime 交接和会话保留结果会单独生成私有安装验收记录；本文件不提前宣称尚未执行的发布操作已经成功。
