- CLI RSI 最终 17 项通过：真实 Worker 和 read_file 的双臂运行、候选不激活、精确 revision、已完成恢复不重复、孤儿先 interrupted 再恢复、未知用量、turn 预算耗尽、holdout 不退款及跨实验累计、固定账号配额、holdout-first/reversed 顺序及完整前置覆盖、非空技能和恢复、上传阶段及父子排序、缺父孤儿拒绝和同 ID 并发不可覆盖。

- 智能体注册表最终回归：22 通过（原有 14 项及新增 8 项冲突解决回归）。覆盖同版本分叉新版本、保留两分支历史、明确接受云端和固定状态、删除的恢复 / 接受、云端 412、本机编辑插入、存储锁内最终 CAS 、账号切换中止及点击到 Runtime 排队执行之间的账号意图检查。

- Web 完整套件在实现快照下 135 通过；最后调整的智能体库及实验区 8 项通过，前端类型检查与构建通过。界面只显示紧凑摘要，ID、hash 与原始 JSON 默认折叠；官方先 fork，账号切换清空草稿和结果。

## 验收边界

本次 Mock 使用正常 Worker 和工具运行，但响应由确定性夹具产生。`offline_pipeline_passed` 只证明工程流水线，不证明模型质量提升，也不授予官方晋升资格。真实模型执行仍硬拒绝；真实模型、题量、价格和总预算必须在后续单独确认。

完整 core 与 Web 套件是较早实现快照的回归结果；最后新增的契约、技能、竞态、顺序与界面修订分别使用对应最终测试组、全目标静态检查及构建复核，未将不同快照的用例数相加成一场测试。

三端最终 HTTP、48 次双臂和实际浏览器验证由主任务统一验收并另存报告，不能仅依据本文件推断这些联验已完成。Debug Web 在本地读取 `web/dist`；正式发版还需要独立核验打包 payload。本批没有执行发版。
