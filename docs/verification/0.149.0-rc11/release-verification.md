## 失败与复验

- Web 首次默认并发全量为 429 项通过、1 项超时：`ChildSessionsP2` 的 16 项前置任务选择用例超过 5 秒。未修改测试或放宽超时；单文件 26 项全部通过，随后限制两个 worker 的完整 430 项全部通过。
- 三处 Rust 静态检查阻塞通过最小调整解决：测试专用方法只参与测试编译；删除无调用入口；用词法作用域结束闭包借用。分享页导出根组件，并移除模块常量的 effect 依赖。没有降低检查规则。
- npm 测试首次使用强制 Ruby 内部 UTF-8 编码，导致二进制夹具转码错误。恢复项目标准命令后，7 runs、38 assertions 全部通过，没有修改安装代码或测试。
- iMac 首次传源码时 Git 引号路径导致中文文件找不到；改用 NUL 分隔路径后传输成功，没有改文件名。
- 全树空白检查会命中历史终端原始采样的真实填充空格和空行。代码与普通文档差异检查通过；保留 `docs/verification` 中的原始证据，不做 trim，也不放宽全局检查规则。
- 浏览器预览启动器解析到原 Xedit 项目的配置，CLI 配置未启动。本次没有浏览器成功截图；实际 TUI 已由隔离运行验收，Web 静态检查调整由 lint、TypeScript、生产构建和 Web 测试验证。

## 验证边界与交付时点

验证门禁仍要求当前稳定快照中的成功检查；调用错误本身不提供成功证据。真实编译/断言失败、强制命令、cwd 和其他参数范围保持约束。旧检查点迁移仅采信完整且无歧义的原始调用/结果。生产分离式后台任务覆盖终态收集、去重、重启与身份约束。

iMac 预编译源码包含未提交修改，只用于验证双架构可编译，不能作为正式发布或安装的最终产物。正式产物须从干净发布提交构建，核对内嵌完整提交号、版本和两个架构。

记录时尚未提交组合、发布、安装或升级 Runtime；后续发布结果单独记录。用户真实会话 JSON 未修改，Provider 退避状态行仍为独立待办。
