## 保证边界

- 文件 SHA-256 是内容版本；逐文件原子安装不是跨文件事务，也不提供对任意外部写者的文件系统 CAS。
- diff 使用成功安装后的绑定快照，不增加模型、Git 或 Shell 调用；每文件 8 KiB、总计 64 KiB、最多 32 文件。有界差异算法退化时明确截断，增删数可能不是最小编辑距离。
- 当前命令自动展开、手动优先和来源重排属于显示状态，不写入模型上下文或执行证据。公共事件剥除完整命令和 `edit_display`。
- 新 operator 输入独立验证范围不代表旧任务完成；replay、host、活动 Goal、显式完成契约、真实失败及未知副作用继续受验证门禁约束。
- 页面来源控制不是 Chrome 全进程网络隔离；浏览器要求 OS sandbox 为 Off，非 Unix 截图仍拒绝。
- 模型策略仅约束已接入的 Provider HTTP 出口；磁盘 journal 不签发 Goal live authority。
- 本地合成 Provider 不测真实模型质量、Token、费用或提速；未调用付费模型或付费搜索。重复空参数收敛、规则刷新编排、失败分类和上游原始协议取证仍未实施，见[效率诊断](../../research/2026-11-17-tool-call-efficiency.md)。
- Windows GNU 交叉 Clippy 不代表 Windows 原生执行、CI 或发行。P2、DAP、Computer Use/AX、语音、ACP、后台预压缩和 `/btw` 不在范围内。
