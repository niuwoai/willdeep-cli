# 发布前后台通知归属回归

日期：2026-10-20。版本：0.108.0-rc3。

本次发布包含项目会话启动选择、长 sleep 自动后台及可继续输入提示、详情弹窗 Esc 鼠标关闭，分别见前序验收目录。

优化构建真实终端联调发现：TUI 先领取完成通知时，通知进入 TUI 的独立内核，Runtime 可能未收到结果便结束。修复后，活动 Runtime 独占投递；空闲 TUI 取得会话执行锁后才可接管，且在锁内持久化。前台本地执行继续使用共享内核，不延迟完成通知。

确定性回归覆盖：活动 Runtime 不被抢领、尚未刷新状态的 TUI 遵守其他执行者的锁、空闲接管且只投递一次、本地活动轮次持有锁时仍能投递到共享内核。

优化构建真实 TUI + Runtime 联调通过：`sleep 30; cd ...` 未设置后台标志，仍整体转后台；等待期间通过实际输入区回车发送的插话在命令完成前被模型读取，命令执行一次、插话保存一次，完成结果回到模型，界面显示可以继续输入。结果见 [tui-report.json](tui-report.json)。

CLI 单元测试 777 项通过、1 项既有忽略；脱离进程集成 18 项通过、1 项既有忽略；Runtime 集成 34 项通过；内部依赖版本一致性通过。严格工作区 Clippy、Web build/lint、格式、源码大小边界和 diff 空白检查通过。优化构建启动选择 11 个场景全部通过，详情弹窗鼠标关闭保留完整草稿。

验收脚本使用隔离 home、工作区、mock Provider 和 Runtime，不读写用户原任务。发布、安装和 Runtime 接管需另行以实际运行版本及原会话历史核验。
