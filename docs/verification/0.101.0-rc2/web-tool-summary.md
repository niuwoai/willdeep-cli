# Web 工具调用折叠与滚动条验收

- 版本：0.101.0-rc2；日期：2026-10-14。
- 基于智能体库 P0—P3 的本地提交 ea6f571，在独立分支 codex/fix-web-tool-summary 修复。
- 历史回放与实时活动使用同一显示分组；原始消息、ID 和运行时更新保持独立。正文、用户消息、计划、分隔符与思考形成分组边界。
- 默认一行调用数摘要；运行中或失败时最多第二行，失败总数可见。展开保留全部步骤、命令详情与已有耗时，详情区最多 320px 高并可滚动。
- 聊天、会话列表与工具详情统一 14px 滚动条，两侧各 1px 透明边框；可见滑块约 12px。原聊天样式为 9px、两侧各 2px，实际可见约 5px。
