## 发布前补充回归

组合复核发现并修复三处边界：

1. Web 子任务完成自动唤醒父会话后，确认策略需要按持久批次和来源继承。覆盖旧记录、已删除来源 Turn、后加入 Web 成员、跨多次唤醒及模型伪造参数。
2. 提议在准备失败后不能因已有 assignment 而消失。失败错误持久化，暂停后台准备；显式重试复用身份，关闭前恢复已落盘 Turn，不能取消实际已经开始的任务。
3. 旧 Runtime 缺少提议能力时，能力错误必须经过上下文包装后仍保持结构化类型，并映射 HTTP 501，保留客户端兼容处理。

新增测试最初暴露两处测试代码问题：将内部 `RuntimeTurnStatus` 误写为协议 `TurnStatus`，以及混合唤醒夹具先结束尚未取得唯一执行槽的任务。修正类型与真实调度顺序后重新执行；没有降低生产准入限制。格式检查发现新增模块顺序问题，也已修正。
