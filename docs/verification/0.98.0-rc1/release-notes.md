新增 CLI 多附件管理和 Runtime 原生定时任务，Web 同步提供配置、历史和维护入口。

- CLI `F3` / `/attachments` 管理草稿附件，`Ctrl+Q` 管理待发消息，按 `A` 管理所选消息附件；预览、编辑、删除与排序均保留原输入草稿。
- Web 附件与待发消息采用紧凑预览和统一图标操作，保留提示与键盘标签；支持已发送附件只读查看和引用。
- 定时任务由 Runtime 持久管理，支持时区、单次计划、预算、超时、去重恢复、连续失败暂停及分页运行历史。插件关闭不停止原生计划，旧插件停用任务迁移为暂停。
- Web 与 `willdeep schedule` 共用管理接口，支持编辑修订检查、暂停、立即运行、归档、停止、显式重试和历史清理预览。

验证：真实隔离 CLI 管理流程、Web 浏览器、轮次/Token 限制、超时无重放、运行用量和保留历史；终端原生图像协议与字符降级输出。Web 本页待发队列暂不跨刷新持久恢复；物理终端 GUI 未验证。
