# 0.143.0-rc4 Windows Clippy 不可达语句修复验收

日期：2026-11-05。平台：本机 macOS arm64，另以 `x86_64-pc-windows-gnu` 目标交叉检查 `cfg(windows)` 代码。状态：Windows CI 的 Clippy 失败已定位并修复；本次提交尚未发布，未执行的平台见文末。

## 根因

- 0.143.0-rc3 的 Windows CI 在 `test (windows-latest)` 的 **Clippy** 步骤失败，`Test` 步骤全部通过：`error: unreachable statement`，位置 `crates/willdeep-cli/src/daemon/child_sessions/worktree.rs:274`。
- `copy_untracked` 处理快照基线中的未跟踪符号链接时，`#[cfg(not(unix))]` 分支调用 `anyhow::bail!`（展开为 `return Err(...)`），其后仍有 `copied += 1;` 与 `continue;`。Windows 上这两句永远不可达，`-D warnings` 把 `unreachable_code` 升为错误，`willdeep` 二进制编译失败。
- macOS 本地 clippy 看不到该分支（`#[cfg(unix)]` 生效），所以此前本地检查全绿。该问题从 0.143.0-rc1 起即存在，前两轮被 Test 步骤的失败遮挡。

## 修复

- 把 `copied += 1;` 与 `continue;` 移入 `#[cfg(unix)]` 分支块内；`#[cfg(not(unix))]` 分支只保留 `bail!`。Windows 快照工作树仍拒绝未跟踪符号链接，产品行为与既有平台限制不变。
