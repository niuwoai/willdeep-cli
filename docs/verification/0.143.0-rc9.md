# 0.143.0-rc9 原生 Runtime 测试夹具回收来源记录

日期：2026-11-05。本文归档独立分支 `claude/affectionate-khorana-66872a` 的验收事实，基线为 `f2094c07`（0.143.0-rc8）。该来源仅修改测试夹具与版本元数据，不包含完整子会话 P2；以下结果不是 0.145.0-rc1 组合源码的新验收。结构化摘要见[同版本 JSON](0.143.0-rc9.json)，组合验证见[0.145.0-rc1](0.145.0-rc1.md)。

## 修复范围

旧升级测试在首个 Provider 请求前派生裸 Child，提前 panic 后客户端仍可能启动 detached Daemon。原 teardown 的单次 daemon stop 又可在状态尚未创建时提前成功；两个缺口均早于 P2。

来源补丁为 CLI/Web/升级进程建立 ChildGuard；每个夹具复制唯一私有可执行文件，使用系统进程 API 核验完整映像路径。先对精确合成 home 正常停止，再在十秒清理预算内定向回收仍匹配该私有映像的进程。Windows 在同一进程句柄上验证与终止；所有枚举共享绝对截止时间，连续两次空快照后才删除成功夹具目录。正常退出也报告清理失败，panic 路径避免第二次 panic；显式停止后重启仍由 Drop 清理。

没有修改产品启动、停止、超时、取消或调度逻辑，没有放宽原业务测试期限。
