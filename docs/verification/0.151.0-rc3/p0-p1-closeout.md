## 本版本修复的收口问题

- Turn/Session 写入失败时恢复前态，使正常 buffered replay 能重试；等待者只在 Task、Agent、Turn 补齐成功后收到裁决。保留其他真实运行通道、取消中与终态任务的保护。
- 完成路径在 Session→Turn 一致锁序下识别当前前台预留；已认领但未绑定的 Queued 轮次保留，普通未认领队列不参与抢占。
- 晚到的启动失败保留 Cancelled、Completed、Partial、Interrupted 终态与当前 Session；Failed 重放仍可补齐写盘，保留首次错误及完成时间。新增取消竞态先实际执行 1 项失败；作者限定修前 223 项中 220 通过、3 项失败，修后 223 项通过。主会话已核对源码，最终工作区回归尚待完成。
- 浏览器 `open` 按实际 frame/loader 的提交与 DOM readiness 等待导航，避免旧页面就绪或正常代次变化导致提前成功/自失效；保留陈旧引用拒绝、`UNKNOWN` 与禁止自动重试。
- 复制确认复用既有两秒保持机制；通过剪贴板依赖注入验证实际入口，不触碰宿主剪贴板。
- 历史轮次结束行紧贴上一轮输出，跳过其上方基础与配置行距。单条渲染不再把每条历史分隔线当作聊天末尾，兼容旧记录及语言切换；仅当前末尾显示一次「轮到你」。定向回归修前实际执行 18 项，其中 15 通过、3 失败；修后 18 项全部通过，0 失败、0 忽略。真实 PTY 由后续 0.152.0-rc1 组合验收覆盖。
- 队列消息在首次有序开始事件时正式落位，移到上一轮完整输出之后；清除对应待发回执，并保留原始时间、附件、消息身份和阅读/选择来源。

修复是否通过以最终结果为准。rc2 的首轮九例通过、后续导航失败及复制确认超时都保留原始经过，不相互覆盖。用户追加的身份提问实录证明，新输入会被上一轮 partial 的验证基线牵引；该边界修复已在 `0.152.0-rc1` 通过 78 项 Core 限定检查和两个入口检查，队列选区专项亦已完成。它们的最终全工作区和固定二进制验收由 `0.152.0-rc1` 接续，本页不补写为 rc3 的最终通过。

## 保证边界

- 文件 SHA-256 是内容版本；逐文件原子安装不是跨文件事务，也不提供对任意外部写者的文件系统 CAS。
- TypeScript 原生未版本化 `changes` 绑定请求前同步文本；Rust 要求版本化 `documentChanges`。
- 页面来源控制不是 Chrome 全进程网络隔离；当前要求有效 OS sandbox 为 Off，非 Unix 截图仍拒绝。
- 模型策略约束已接入的 Provider HTTP 出口，不约束任意插件或外部进程。
- 磁盘 journal 不签发 Goal live authority；重启缺少实际权限时需重验。
- 本地合成 Provider 不测真实模型质量、Token、费用或竞品成绩；未调用付费模型或外部付费搜索。
- Windows GNU 交叉 Clippy 不代表 Windows 原生执行、CI 或发行；手工性能、DAP、Computer Use/AX、语音、ACP、后台预压缩和 `/btw` 不在本次范围。
