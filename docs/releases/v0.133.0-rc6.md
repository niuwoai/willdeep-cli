# v0.133.0-rc6

本版只补一处配置说明。

## 变更

- 配置页每个提供商的「最大输出 Token」原先只写「一次回复最多生成多少 token」。这个值实际也是上下文压缩、会话标题和跟主模型的 Worker 的输出上限，而且思考 token 占同一额度。写得远小于模型的真实上限时，长会话的合并摘要会被截断，客户端把截断结果当成没有正文，报「provider response did not include a completion」。
- 字段说明改为点明这个关系，中文走 schema，英文走页面内嵌的翻译表。
- `docs/CONFIGURATION.md` 的 `max_output_tokens` 一行原先误写成「Anthropic Messages 的输出上限」，改为三种协议通用，并写明不写时的缺省是 16384。`config.example.toml` 的示例值旁加了同样的注释。

CLI、Runtime SDK、内嵌 Web、npm 清单统一为 `0.133.0-rc6`；服务端继续通过现有 `X-App-Version` 与健康接口暴露版本。
