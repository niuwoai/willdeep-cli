# v0.129.0-rc1 联合发布

日期：2026-10-29。

本版包含计划依赖与并行状态能力，以及 Claude 的默认简洁回复、`/verbose` 与 `/short` 切换。旧会话缺省按简洁模式恢复；计划按稳定步骤 ID 合并，依赖校验与就绪步骤计算辅助 Agent 使用已有后台任务推进独立工作。计划状态本身不是完成证据。

## 发布前验证

- `yarn lint`、`yarn build` 通过。
- `cargo fmt --all -- --check` 通过。
- `cargo clippy --workspace --all-targets -- -D warnings` 通过。
- `ruby scripts/check_source_size.rb` 通过，1111 个手写文件均未超过 3000 行。
- 计划相关 core 15 项、CLI/TUI/SSE 7 项及目标完成验收门禁 1 项通过。
- 默认简洁风格和 `/short`、`/verbose` 切换的两个针对性用例通过。
- Web 全量测试低并发执行：182 项通过，1 项既有失败。失败来自 `ProviderSetup.test.tsx` 的旧插件权限文案断言；对应组件、测试和设置页文案与开发基线一致。
- 本地全量 Rust 测试曾停止在无关的大规模恢复清单用例，完整跨平台结果以本标签触发的 Release 工作流为准，不以本地部分回归替代。

开发阶段计划功能验收记录位于 `docs/verification/parallel-plan-0.129.0-rc1.md`；其中“未提交、未发布”的标记是该阶段快照，不表示本发布记录的当前状态。

发布工作区只纳入上述两组代码及版本文档。原工作区中的模型评估数据、日志、node_modules 和构建目录不进入本次提交。官网没有固定的旧 CLI 版本或下载资产地址，无需版本修改。

## 分发与安装

目标标签为 `v0.129.0-rc1`，位于合并到 develop/main 的提交上。Release 工作流负责 Linux amd64/arm64、Windows x64、macOS universal 及 npm 分发；Homebrew formula 在实际 Release 产物就绪后更新校验和。本机 Cargo/Homebrew 和 Runtime 的安装状态应以发布后的实际版本核对为准。
