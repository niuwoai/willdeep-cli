# v0.133.0-rc4

本版只修 TUI 的一处回显延迟。

## 修复

- 一轮还在跑时按 Enter 发出的消息立即回显。此前它只进 Runtime 队列并清空输入框，聊天区要等这一轮结束、下一轮任务启动才写出这句，长轮次里要等好几分钟；向上箭头的历史输入只读会话文件，落盘前同样找不到。
- 回显是聊天记录里的一行。简洁模式（默认，以及 `/short`）只把中途文字收进底部那行会替换的状态，不碰这行；下一轮任务启动时补发的那条事件认领已有的回显，不会再写一行。
- 这条消息在队列里被删除或改掉、还没轮到发送时，回显行改成「未发送」。已经开始的下一轮不受影响。
- 暂缓提交（Cmd+Enter、`/queue add`）不变：它本来就还没发，仍显示在待发队列里。
