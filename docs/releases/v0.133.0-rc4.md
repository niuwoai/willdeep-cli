# v0.133.0-rc4

本版与 v0.133.0-rc3 内容相同，只修正 rustfmt 格式。v0.133.0-rc3 的 tag 已指向格式检查不通过的提交，按发版规则不移动已推送的 tag，递增 rc 重发。

本版只改 TUI 的过程显示。简洁模式此前只改了提示词，聊天区仍把每段中途文字和每次思考都堆成一行，看起来和详细模式没有区别。

## 变更

- 简洁模式（默认，以及 `/short`）干活时聊天区只留两样东西：计划卡片，和底部一行会替换的状态。状态行是最近一段定稿的中途文字，带旋转符和已运行时长；下一段来了就换掉它。轮次收尾时这行才落成正文。计划围栏照旧原位更新卡片。
- 详细模式（`/verbose`）不变，中途文字仍逐段落进聊天区。
- 连续的思考记录只显示最后一条，两种模式都生效。点开过的那条留在原处，被收起的指向留下的那条，搜索跳转不受影响。原始记录不删除，`/tools` 只展开工具行。
- 中断或状态复位时，还挂在状态行上的最后一段会补写进聊天区，不随状态行一起消失。
