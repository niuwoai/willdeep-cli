# v0.134.0-rc7

本版补配置页的技能与规则管理，把系统提示词按提供商缓存重排，并修掉 TUI 滚动时的屏闪。末一项是 0.134.0-rc6 合入时带进来的 clippy，rc6 的 tag 已指向 CI 不通过的提交，按发版规则不移动，递增 rc 重发。

## 变更

- 配置页的「技能」分组列出已发现的技能：名称、一行说明、档位和来源目录。能查看和编辑 `SKILL.md`，也能在用户技能目录里新建、删除。从 GitHub 安装接受 `https://github.com/拥有者/仓库`、`拥有者/仓库` 或带子目录的地址，拉 `codeload.github.com` 的 zip，拷贝到 `~/.willdeep/skills/<名字>`；同名已存在就拒绝。只接受 `github.com`，拒绝凭据和私有仓库，下载限 32 MiB，解压限 64 MiB，压缩包里越界的路径直接丢弃。技能正文仍不进系统提示词，提示词里只有一份有界的目录。
- 配置页的「规则」分组用 `[rules].files` 列出多份规则。每一项是一个文件或一个目录，目录里的 `*.md` 按文件名拼接。能启用、停用、排序、编辑，也能从 GitHub 安装。没有 `[rules]` 时仍读 `~/.willdeep/CLAUDE.md`，旧配置不用改；写了 `[rules]` 之后那个文件不再自动加进来。单个文件上限 256 KiB，合计上限 512 KiB，超限或读不动的部分不拼进去，提示词里留一行说明。
- 第一次启动且 `~/.willdeep/rules/` 还不存在时，写入内置的 agentrules 精简版（`agentrules.md`，只留每个主题的 MUST / MUST NOT）。目录已存在就什么都不做：不覆盖用户改过的文件，也不把删掉的规则加回来。写入不等于启用，要在配置页打开。
- 系统提示词把稳定内容放在前面：契约、全局规则、技能目录、简洁风格与插件路由；工作区路径、项目规则、计划与预算放在明确的分界之后。Anthropic 请求只在分界之前打 `cache_control: {"type": "ephemeral"}`，换工作区或预算数字不再把整段缓存打掉；规则或技能目录变了才失效。其余提供商走自动前缀缓存，同一个顺序对它们同样有效。Worker 没有自己的项目规则，继承用户配置的全局规则。
- TUI 滚动时不再屏闪。滚轮事件没有位移量，一格固定 3 行，触控板一划会连续送出几十格；此前每一格都让事件循环画一整帧，聊天区被逐段重写进终端。现在同一次手势里已经到达的滚轮格先合成一份偏移再画一帧，方向相反的互相抵消，碰到按键或鼠标移动就停下来，剩下的事件交还原处处理。每一帧用同步更新包起来，支持的终端攒到帧尾一次性翻页，不支持的忽略这两条序列。侧栏和各个详情层的滚轮走同一条合并。
- 修正 rc6 合入时带进来的两处 clippy：向上箭头的历史输入改用 `filter` 加 `map`，压缩状态行插入聊天区时不再多调用一次 `into_iter`。`-D warnings` 下发布校验因此通过。

CLI、Runtime SDK、内嵌 Web、npm 清单统一为 `0.134.0-rc7`；服务端继续通过现有 `X-App-Version` 与健康接口暴露版本。
