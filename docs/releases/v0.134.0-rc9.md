# v0.134.0-rc9

收紧 TUI 的聊天区：工具调用只留最近一批的一行汇总，斜杠命令不再回显，每条消息带上模型名，失败时两行并成一行。

## 变更

- 工具调用只显示最近一批，收成一行「已收起 N 条工具调用」，不再列出具体是哪些工具；有失败时同行报失败数。更早的批次连这一行都不显示。只有一条的批次原样保留，不配汇总。`/tools` 仍能把全部工具行展开，记录本身不动。
- 只改状态的斜杠命令不再回显成一行 `You:`。`/model`、`/help` 这类留在聊天区里只是噪声，结果仍由命令自己写一行说明。`/goal`、`/local`、`/runtime` 会开工，那句是用户的任务，照常显示。
- 每条消息的相对时间后面带上产出它的模型名。会话不记逐条模型，历史消息一律用会话当前的模型；切模型或换会话时更新。没有模型名时只显示时间。
- 任务失败时 `Error:` 和「失败原因」两行并存，只留一行「失败原因: …」。`Error:` 那行只有失败分类，具体原因到来后就把它去掉；没有具体原因时 `Error:` 照旧留着。中文、英文、日文各认各的两行。

CLI、Runtime SDK、内嵌 Web、npm 清单统一为 `0.134.0-rc9`；服务端继续通过现有 `X-App-Version` 与健康接口暴露版本。
