# v0.137.0-rc1

## Added

- 实例身份：首次使用时生成终身不变的 UUID，并从 64 个内置名字里挑一个实例名，存进 `$WILLDEEP_HOME/identity.json`（0600，原子替换）。TUI 与 Web 的 `/name [新名字]` 查看或改名，`willdeep identity [show|rename|names]` 是命令行入口；Web 侧栏标题旁的实例徽标点一下也能改名。改名不换 UUID；重名时展示为 `alex:2u2d`；文件损坏直接报错，不会静默换身份。
- 公网入口表单设计器：表单 slug 由标题自动生成，字段名由显示名自动生成，重名时自动加 `-2`、`-3`。手动改过之后不再跟着变，清空则交还给自动。中文标题没有可靠的转写，slug 退到 `form` 占位并在下方说明。字段类型会按显示名猜：邮箱、电话、网址、日期、数字、多行文本都认得。
- 表单字段新增数字、电话号码、网址、日期四种类型。数字可以设是否允许小数以及最小值、最大值；前端校验、配置校验、入口页控件和提交校验共用一套规则，范围外的提交在入口就被拒绝。
- 字段可以上移、下移排序；类型下拉按文本、联系方式、其他分组。

## Changed

- 字段编辑器改成一张小卡：第一行是显示名、类型、必填和排序，第二行是内部字段名并标出「自动」；数字字段展开范围设置，单选字段展开选项。
- 公网表单页补上移动端视口和基础样式，必填项加星号，各类型使用对应的 HTML 控件（`number`、`tel`、`url`、`date`），并限制单字段长度。
- Web 侧栏的「显示已归档」固定在会话列表下方，不再跟着滚动区滚走；展开的归档列表限高 34vh 自己滚动。
- Web 侧栏的会话条目收紧行高：标题内边距从 11px 收到 6px，行间距从 3px 收到 2px。
