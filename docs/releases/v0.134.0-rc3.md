# v0.134.0-rc3

本版只修一处配置校验不一致：子代理的 `max_turns` 写到 128 能保存，任务跑起来才报 `must be between 1 and 32`。

## 变更

- `[subagents.<职责>] max_turns` 的合法区间从 1 到 32 改为 1 到 1000，与 `[agent] max_turns` 同一个上限。32 是 0.52.0 时为了让 `ops_runner` 的内置默认值（32）能通过校验才从 24 抬上去的，不是运行时的能力边界；跑超上限只交出部分结果，不判失败。
- 配置页补上整数区间校验。此前 schema 只校验类型，所以页面能存下运行时拒绝的值。带 `min`/`max` 的整数字段现在在写入前拒绝越界值，页面输入时当场提示区间。已有配置不受影响：不写 `max_turns` 仍用该职责的内置默认。
