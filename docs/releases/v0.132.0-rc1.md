# v0.132.0-rc1

本版为功能新增：Web 执行计划卡的状态图标与进行中动画，以及 TUI 输出流中计划状态卡的补建。

## 变更

- Web 执行计划卡：待开始、进行中、已完成、已跳过、失败、阻塞各用独立图标；等待依赖的步骤显示时钟图标并标注依赖步骤。进行中的图标以 1.1 秒线性旋转，系统开启减少动态效果（`prefers-reduced-motion: reduce`）时停止动画。状态列图标与文字对齐，窄屏下不挤压步骤正文。
- TUI：同步持久化计划时，如果输出流里没有对应的计划卡，就补一张；同一计划后续同步原位更新，不重复追加。覆盖 TUI 中途接入 Runtime 会话、漏掉计划事件、计划在会话恢复后才出现等场景。计划卡继续显示完成数、进行中数量、每步状态与等待依赖关系。

## 验证

- Web：`ConversationCard.test.tsx` 5 项通过，覆盖每种状态都有图标、仅进行中的图标带旋转类；浏览器夹具渲染已完成、运行中、等待依赖、待开始（被依赖）、已跳过、失败共 6 种状态，全部有 SVG，运行中元素的 computed animation 为 `plan-spin 1.1s linear infinite`，其余无动画。
- Web 全量 vitest 198/199 通过，唯一失败为 `ProviderSetup` 历史用例——期待已移除的旧插件审批文案 `Review willdeep-config permissions`，与本次改动无关；`yarn lint`、`yarn build` 通过（仅保留既有大包提示）。
- TUI：`cargo test -p willdeep tui::plan_ui` 7 项通过，含新增 `persisted_plan_without_a_card_is_appended_once`：空输出流连续同步两次只补一张卡，状态取持久化计划。
- `scripts/check_source_size.rb` 通过（1452 个文件，无 3000 行超限）。

## 兼容边界

只改 Web 计划卡的状态图标与动画，以及 TUI 的展示补卡；计划生成、状态推进、Runtime 协议和会话存储不变。Web 图标仅在前端渲染，不写入会话；TUI 补建的卡片同样只存在于显示层，后续同步按计划步骤原位更新。
