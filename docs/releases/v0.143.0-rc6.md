# WillDeep CLI 0.143.0-rc6

本版本调整 macOS 发行构建使用的 runner，继承 rc5 的插件固定入口修复、完整子会话和 Magpie 集成。macOS 发行包继续是 Intel 与 Apple Silicon 双架构的 `willdeep-macos-universal.tar.gz`。

## 发行配置

默认 macOS arm64 runner 在 rc5 的两次发行尝试中均未被分配；两次取消都发生在任何构建步骤执行之前。改用显式 `macos-26-intel` runner，仍分别编译 `x86_64-apple-darwin`、`aarch64-apple-darwin`，再用 `lipo` 合并。Linux/Windows 构建、完整验证矩阵、GitHub Release 和 npm 发布依赖关系保持原有要求。合包后用 `lipo -verify_arch` 检查双架构；发布前核对 tag 与 Cargo、Web/npm、安装清单及产品/架构/CHANGELOG 的版本一致。

## 版本与验证

Cargo workspace、两个内部 runtime 依赖版本、Cargo.lock 四个工作区包、Web/npm 包及安装清单统一为 `0.143.0-rc6`。rc5 标签保持原指向。

历史依据：rc5 的 [Release 流水线](https://github.com/niuwoai/willdeep-cli/actions/runs/41875495989)两次尝试中，其余九项作业均成功，包含 Windows/Linux/macOS 测试与 Clippy。该结果属于 rc5；rc6 的发行包、安装与健康检查将单独记录，不提前视为已发布。
