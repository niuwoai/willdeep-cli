# v0.133.0-rc8

本版修掉 TUI 滚动时的屏闪。

## 修复

- 滚轮事件没有位移量，一格按 3 行算，触控板一划会连续送出几十格。此前每一格都让事件循环画一整帧，聊天区几乎每个单元格都被判成变了，于是整片重写进终端；终端逐段画出来，看起来就是闪。
- 同一次手势里已经到达的滚轮格先合成一份偏移，再画一帧。方向相反的互相抵消；碰到按键、鼠标移动或读取出错就停下来，后面的事件原样交还，一格不丢。
- 每一帧用同步更新（DEC 2026）包起来：支持的终端把一帧撸到帧尾一次性翻页，不支持的把这两条序列当未知模式忽略。
- 侧栏和各个弹层的滚轮走同一条合并，仍然是落点决定滚动哪一块。

CLI、Runtime SDK、内嵌 Web、npm 清单统一为 `0.133.0-rc8`；服务端继续通过现有 `X-App-Version` 与健康接口暴露版本。
