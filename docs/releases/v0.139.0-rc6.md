# v0.139.0-rc6

## Added

- Web 的新会话在发出第一条消息之前就能选模型与审批档位。此前两个面板只在会话存在时出现，而 Web 的会话是第一条消息的副产物，于是必须先发一句、挨一轮默认模型，才能改成自己想要的模型。现在没有会话时选中只记成草稿，跟着第一条消息一起交给服务端，建会话时一次写进会话与 Runtime；升到完全访问仍要在面板里勾选确认。
- 新会话的第一轮把实际生效的模型写进会话，界面上显示的就是真正在跑的那个，而不是一句「跟随 Provider 默认」。没选时按 Web 服务所用的 Provider 档案决定，与模型选择器列的是同一份配置；只有回环监听可以改，远程页面会把选择器置灰。
- 实例名支持中文与日文。此前只允许 ASCII 字母、数字、`-`、`_`，改名会直接报错。名字只在 JSON 里传递（身份文件、联邦 `join`、会话来源行），不进 URL，因此宽字符不必转义；长度按终端列数算（最多 24 列，也就是最多 12 个汉字），空白、控制字符、方向覆盖符与零宽字符一律拒绝——它们会把名字在终端里显示成另一个样子。

## Fixed

- 聊天区拖选终于对得上了。选区以前按「聊天区外框 + 固定偏移」算：完整 UI 有一圈边框还勉强对齐，简洁 UI 只有左右内边距，于是画面上的每一行都错开一行——拖选 AI 回复，松手复制到的是上一行（常常是空行），看起来就是「选不中、也不复制」。现在两种布局都在绘制时记下正文矩形并据此落点，简洁 UI 也补上了选中高亮。
- 从用户消息或工具行上起手拖选不会再被「点开 / 收起」打断：按下只记下行号，真的拖动就作废，没拖动才在松手时点开。此前按下即展开会重排记录，选区坐标随之错位。
- `response.failed` 不再只剩一句「Responses generation failed」：网关给的错误码与错误信息会跟着错误一起出来。比如某个模型不支持带工具的 Responses，以前界面和日志里都是同一句无从下手的话，现在能直接看到「Agent capabilities are not enabled for the current model」。
