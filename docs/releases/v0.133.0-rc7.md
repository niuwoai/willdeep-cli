# v0.133.0-rc7

本版把 TUI 简洁模式的那一层显示补到 Web 聊天区。

## 变更

- 简洁是默认。Web 此前只有提示词侧的简洁：模型少写，但写出来的每一段中途文字都各自占一个气泡，一轮长任务的聊天区比 TUI 密一截。现在干活时只留最近一段，摆在一行会替换的状态上，后面跟着这一段已显示的时长，下一段来了就整行换掉。
- 轮次收尾时这一段落成正文。正文就是它时只落一次；守护进程在前面拼了提示时，提示单独成段，最后一段照旧落。被截断的状态行是正文的前缀时不再单独落一段，避免同一段话出现两遍。
- 轮次被中断或请求失败时，还挂在状态行上的最后一段补写进聊天区，不随状态行一起消失。
- 计划围栏两种模式都原位更新计划卡片，不进状态行，也不落成一段正文。`/verbose` 切回逐段显示，从下一条中途文字起生效。
- 重开会话或轮询刷新时按同样的规则回放：一轮里最后一段正文之外的中途文字不进聊天区，带工具调用的记录保留，工具调用仍收进「N 次工具调用」那一行。这只是显示层的取舍，会话记录一个字不删。

CLI、Runtime SDK、内嵌 Web、npm 清单统一为 `0.133.0-rc7`；服务端继续通过现有 `X-App-Version` 与健康接口暴露版本。
