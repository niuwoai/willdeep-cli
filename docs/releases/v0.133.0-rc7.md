# v0.133.0-rc7

修复上下文压缩丢掉「这段历史需要回传思维链」的信号。0.133.0-rc5 给缺思维链的 assistant 消息补空 `reasoning_text`，但只在历史里还有非空原文时才补。压缩会把带思维链的工具批次替换成摘要或归档引用，原文回不来；这一轮的最近几条又常常是没吐过思维链的直给步骤。判断依据一消失，下一轮 Responses 请求被上游整条拒绝，HTTP 400：`The reasoning_text in the thinking mode must be passed back to the API`。

## 变更

- 摘要和归档引用在被替换的内容出现过思维链时带一个空标记。Responses 与 chat-completions 出站都认这个标记，继续给缺的 assistant 消息补空 `reasoning_text`。
- 空标记不冒充思维链原文：出站时与「没有原文」同样补成空串，摘要正文仍是普通消息。
- 从没出现过思维链的会话不带这个标记，也不发这个项，严格校验未知字段的上游不受影响。
- 标记按 durable 历史每轮重算，不靠摘要缓存记住。
