# WillDeep CLI 0.143.0-rc7

本版本修正 macOS universal 发行检查，并降低 Windows 上不同测试用例之间的资源争用。继续包含侧栏固定插件、完整子会话与 Magpie 集成；产品运行超时和平台支持范围保持原有设置。

## 发行验证修复

- macOS Intel runner 已在 rc6 成功完成两个 Apple Darwin 目标编译；新增的 `lipo -verify_arch` 调用将文件名误解析为架构参数，导致合包检查失败。rc7 改由 `scripts/check_macos_universal.rb` 读取 `lipo -archs`，严格检查 arm64、x86_64 两个架构。
- 架构检查在本机用 Clang 生成的真实双架构、单架构 Mach-O 与缺失文件执行，分别通过、拒绝、拒绝。
- Windows CI 使用 `cargo test --workspace -- --test-threads=2`，保留全部测试和用例内部并发，随后继续执行 Clippy。其他平台保持默认测试并行度。

## 历史依据与边界

[rc6 Release 流水线](https://github.com/niuwoai/willdeep-cli/actions/runs/41885876919)的 macOS 架构检查失败，Windows 验证另有四项超时（其余 CLI 测试为 1275 通过、4 忽略）。定向核查未发现相关实现从 rc5 到 rc6 的代码变化；涉及真实 MCP/Python 进程启动、64 个任务取消后的持久化收尾，现有证据支持负载下的时间波动，但不宣称已证明唯一根因。

保留 rc5、rc6 标签与失败记录，正式发行版本顺延为 `0.143.0-rc7`。本文件是提交前说明，不代表 rc7 已公开发布；最终 Windows、macOS 双架构发行与安装结果由新流水线和安装回执核验。
