# v0.140.0-rc1

## Added

- Web 模型选择器采用 Provider → 模型级联流程，按所选 Provider 加载模型目录并支持搜索。切换 Provider 会清空搜索；会话详情和模型变更都保留 Provider 身份，避免同名模型混淆。
- 新会话在发送第一条消息前即可选择模型和审批档位；未指定模型时显示实际生效的默认模型。
- 配置工作区新增实例名编辑入口。内嵌配置页按所选 Provider 加载模型候选，也保留手动输入模型名的方式。
- 实例名支持中文、日文等宽字符，并作为动态上下文提供给模型；WillDeep 的产品身份保持不变。

## Changed

- Web 侧栏将「配置」和「插件」设为并列一级入口。配置菜单包含模型配置、公网入口、MCP、智能体和 RSI；插件菜单按需展开插件中心与已启用插件。
- 定时任务管理改用横向状态标签，并显示各状态的任务数量。
- TUI 首屏只保留小鲸鱼、产品名、版本和欢迎语，会话 id 与续接命令在退出时显示。输入建议统一提示「（按 Tab 键采用）」并淡化，Tab 只填入建议正文。

## Fixed

- 聊天区拖选按正文区域定位并显示高亮；拖动消息或工具行时不会误触发展开与收起。
- `response.failed` 会携带网关返回的错误码和原因，便于判断模型能力或请求参数问题。
