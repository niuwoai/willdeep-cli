# v0.131.0-rc2

本版包含 rc1 的全部改动，并修复 Web 工具调用展开后的行重叠。rc1 的 Release 工作流已取消，未生成 GitHub Release；rc2 为当前发布版本。

## 变更

- Web 工具调用卡片展开后，每个步骤在 320px 高的滚动列表里保持自身高度，不再被压进相邻步骤：标签与耗时占第一行，命令详情另起一行并缩进；长命令完整换行，超出高度在卡片内滚动。
- 其余改动与 rc1 相同：Web/TUI 长用户消息折叠、Web 问题卡片单列操作、Runtime 活动面板指标磁贴与面板内滚动、历史思考行映射。

## 验证

- Web：RunCard、UserMessage、RuntimeHumanGates、RuntimeSidebar 共 23 项通过；全量 vitest 197/198 通过，唯一失败为 `ProviderSetup` 历史用例——期待已移除的旧插件审批文案 `Review willdeep-config permissions`，与本次改动无关；`yarn lint`、`yarn build` 通过（仅保留既有大包提示）。
- 浏览器夹具展开 14 条工具调用：`.run-details` 可视高度 320px、内容高度 940px，步骤标签与详情边界不相交，卡片内可滚动；375px 窄屏无横向溢出。截图 `target/web-runcard-expanded.jpg`、`target/web-runcard-expanded-mobile.jpg`。
- `scripts/check_source_size.rb` 通过（1451 个文件，无 3000 行超限）。
- rc1 Release 工作流已取消，未生成 GitHub Release；v0.131.0-rc1 tag 保持不动。
