# v0.129.0-rc3：DeepSeek Responses 推理回传修复

日期：2026-10-29。

WillDeep CLI 使用 Responses 接口连接 MuchToken 的 `deepseek-v4-flash` 时，原适配器丢弃返回的 `reasoning_text`，工具续轮没有回传推理内容，导致上游返回 HTTP 400。本版保存原始推理，并在下一轮 assistant 正文与工具调用之前按 `reasoning` / `content[].reasoning_text` 回传。

## 验证

- 修复前的非流式回归用例复现：期望保存推理文本，实际得到 `None`。
- 修复后的 Provider 测试 84 项通过，包含真实本机 HTTP 请求的工具续轮回传、非流式解析、流式增量、终态快照、中断保留、冲突拒绝及 summary 不冒充原始推理。
- 本机端口模拟测试需要允许监听 loopback；受限沙箱下的 bind 失败不作为功能回归。
- 本版版本从修复工作区原定 rc2 顺延到 rc3，以避开另一工作区的 rc2 发布准备。代码未混入其他工作区未提交的改动。
- 完整跨平台构建、安装和实际 MuchToken Runtime 验收以发布后记录为准；本文件不预先声明其成功。

## 兼容性

不修改账号、模型路由或默认 thinking 设置。流式推理与最终快照不一致时拒绝成功提交；不使用摘要或占位文本伪造原始推理。已丢失推理的旧会话不能凭空恢复，验收应使用新会话并实际执行工具调用。

CLI、Runtime SDK、内嵌 Web、npm 清单统一为 `0.129.0-rc3`；服务端继续通过现有 `X-App-Version` 与健康接口暴露版本。macOS 发布产物保留 universal 架构。
