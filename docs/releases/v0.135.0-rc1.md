# v0.135.0-rc1

Web 侧栏从工作区下拉框改成项目树，TUI 的工具行可以点开看完整命令。

## 变更

- Web 侧栏按项目列会话。每个项目默认露出最近 5 个，「显示更多」一次加 10 个，「收起」回到 5 个；点项目名左边的小箭头收起整个项目。会话按最近更新排序，置顶的仍在最前，一个项目最多列 20 个，再旧的不进树。
- 搜索框按会话标题跨所有项目查找。标题还没生成、侧栏上显示首条用户消息的会话，按那段显示文本匹配；命中的全部列出，不受 20 条上限。没有命中时显示「没有匹配的会话」。
- 每个项目名右边有自己的新建按钮，在那个项目里开一个新会话。
- TUI 里点 `run_command` 那一行展开完整命令，再点下面的「收起」收回，和 Thought 那一行同一个手势。凭据照旧打码，路径不再省略。完整命令只留在本机，不进公共事件流；重开一个会话后回放出来的工具行没有这份记录，点开只多一行「收起」。

CLI、Runtime SDK、内嵌 Web、npm 清单统一为 `0.135.0-rc1`；服务端继续通过现有 `X-App-Version` 与健康接口暴露版本。
