# v0.136.0-rc1

本版让 Web 能管会话、也能把一条会话分享出去。

## 新增

- 授权模式面板：工具栏里显示当前生效档位（跟随工作区或显式覆盖），改档走 `POST /api/sessions/{id}/approval-mode`，与 TUI 同一条 Runtime 通路，对正在跑的轮次立即生效。`full_access` 需要额外确认，`read-only` 工作区不能从 Web 越过。
- `/model`：候选来自配置里的 Provider，按 Provider 分组；切换只影响当前会话、下一轮生效，`/model <模型名>` 直接切。
- 会话分享：链接走公网入口的 `/share/<token>`，分享页只有对话正文和输入框，没有配置、插件与工作区。`read` 只看，`chat` 还能继续发言；访客消息作为普通轮次按会话当前授权档位执行，单条上限 8 KiB，每 token 每分钟 20 条。一条会话只有一个 token，重新分享即吊销旧链接。
- 公网入口管理页：站点、表单、Webhook 的增删改、启停与监听地址，表单字段编辑，目录选择器，失败投递与绑定会话的查看入口。
- MCP 接入提为侧栏一级入口。

## 说明

- 授权模式、`/model`、分享管理都只在 Web 监听回环地址时开放。分享页本身是公开的：知道链接的人都能进，需要限制时用反向代理或停止分享。
- 入口监听没在跑、或只监听回环地址时，分享面板会如实说明链接目前打不开。
- 本版同时并入并行分支尚未发布的压缩档案改动（`compressor_profile` / `compressor_context_window`），条目见 CHANGELOG 的 0.133.0-rc11。

CLI、Runtime SDK、内嵌 Web、npm 清单统一为 `0.136.0-rc1`；服务端继续通过现有 `X-App-Version` 与健康接口暴露版本。
