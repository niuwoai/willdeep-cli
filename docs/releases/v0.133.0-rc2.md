# v0.133.0-rc2

本版只修一件事：Web 会话事件轮询在长会话上把 CPU 吃满。

## 修复

- `/api/runtime/events` 的会话归属校验按会话文件的修改时间与大小缓存。
  归属只取决于会话属于哪个工作区，而轮询每两秒打一次；文件没变就直接用
  上次的结果，不再整读会话文件。读失败不进缓存，不会把一次瞬时错误变成永久拒绝。
- 执行指纹改为按需计算。指纹要把整段对话序列化进 sha256，长会话一次几十毫秒，
  而列表、轮询、归属校验这些只读加载根本不写回。`SessionStore::load` 只记标量基线；
  改消息、计划、压缩或检查点再写回的路径改用 `SessionStore::load_baselined`，
  在改动前算好指纹。没有指纹的基线按「没动过执行状态」合并，保留磁盘上的那一份。
