# v0.134.0-rc5

本版只修 npm 页面的 README，程序行为不变。

## 修复

- 0.134.0-rc4 把 `README.md` 放进了 `@niuwoai/willdeep` 包，npmjs 页面仍显示 "This package does not have a README"。原因在发布工具：npm 10 先打包，再从磁盘重读 `package.json` 作为发给 registry 的元数据。打包那一步写进压缩包的 readme 不会出现在这份重读的清单里，registry 收到的 `readme` 是空字符串，页面只看这个字段。
- `scripts/publish_npm_willdeep.rb` 现在把 `README.md` 的内容写进 `package.json` 的 `readme` 字段再执行 `npm publish`。重读时这份内容还在，registry 就能存下。本地用 npm 10.9.2 打包验证过，压缩包内清单的 readme 不为空。
- 安装器不变：仍按包版本下载对应的 GitHub Release，校验 SHA256，确认包内只有预期的可执行文件，再写入 npm 的 bin 目录。
