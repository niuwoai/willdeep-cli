# v0.129.0-rc5

Web 配置工作台以前只读取错误中的 `message`，而 Web API 的失败响应使用 `error`，导致缺少 Ruby 等真实服务错误显示成「读取配置失败：?」。现在桥接层保留错误说明和 HTTP 状态，并对代理登录页、非 JSON 及无效响应给出本地化提示；正常 MCP 结果与工具校验错误继续按原契约处理，不自动重试配置命令。

## 验证

- 6 项桥接回归测试通过，直接执行 Rust 注入脚本与内嵌配置页解析器；已加入各平台 CI。
- 配置服务 Ruby 测试、配置页逻辑测试通过。
- Web TypeScript/Vite 构建、Rust `cargo check -p willdeep --locked --offline`、`cargo fmt --all -- --check` 通过。
- 故障 Linux 主机补齐发行版 Ruby 3.3.8 后，原 Runtime 未重启，配置快照由 HTTP 500 恢复为 HTTP 200、`ok: true`，读取 14 个配置分组且无解析错误。该恢复来自依赖修复，不代表已部署本版本。

## 范围

完整配置工作台仍依赖运行 Web 服务主机上的 Ruby；本版本没有内嵌 Ruby，也不会自动安装系统包。相关排查步骤见 `docs/TROUBLESHOOTING.md`。CLI、Web、Runtime SDK 和 npm 安装清单统一为 `0.129.0-rc5`。
