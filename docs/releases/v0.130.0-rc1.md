# v0.130.0-rc1

- Web 智能体库可转换 Hermes profile（config.yaml + SOUL.md）和 Multica 单个 Agent JSON，预览后选择本机模型绑定并保存。转换覆盖名称、指令和模型引用；其他字段明确列出，默认只读，凭据不复制。定义和模型绑定原子写入，重复 ID 拒绝。
- TUI 空输入按 ↑ 就地选择当前会话历史输入，Enter/Tab 仅回填；多行文本与附件保留。
- 历史轮次默认隐藏思考耗时，合并被思考行分隔的工具调用；最新轮次保留过程，点击思考仍定位正确。

验证：Web 构建、ESLint、导入和智能体库回归；TUI 回归与历史折叠专项；导入绑定原子性专项。

兼容边界：本版没有迁移外部 Runtime、MCP、环境变量、工具权限和技能；上下文/轮次预算未由转换器配置。图片或视频执行能力仍受 WillDeep 当前 Worker 支持范围限制。
