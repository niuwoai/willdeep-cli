# v0.135.0-rc2

与 0.135.0-rc1 功能相同，只修掉工具行摘要对带引号路径的省略。

## 修复

- 工具行摘要认不出包在引号里的路径。`'/home/ml-data/run.py'` 和 `"~/notes"` 不以 `/` 或 `~` 开头，省略判断原样放行，路径漏进摘要行。判断前先剥掉一层单引号或双引号。点开后看到的完整命令不受影响，本来就不省略路径。
- 0.135.0-rc1 的验证测试因此在 Linux aarch64、Linux x86_64、Ubuntu、macOS、Windows 五个 job 上失败，GitHub Release 与 npm 发布被跳过。rc1 的 tag 已指向该提交，按发版规则不移动，递增 rc 重发。

CLI、Runtime SDK、内嵌 Web、npm 清单统一为 `0.135.0-rc2`；服务端继续通过现有 `X-App-Version` 与健康接口暴露版本。
