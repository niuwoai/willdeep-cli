# v0.131.0-rc1

## 变更

- Web 和 CLI 支持每个 Agent 的上下文窗口、最大轮次与模型绑定；Hermes 导入映射 `model.context_length` 和 `agent.max_turns`。明确的预算优先于 Worker 档位，配置保留在本机。
- Agent 派工预览遵循本机模型绑定，避免预览与实际执行模型不一致。
- Web 单条用户消息超过约 12 行显示高度时默认折叠，点击「显示更多 / 收起」切换；调整窗口宽度后重新判断。全文留在原消息中，附件入口独立显示，展开不会继续跟随新回复滚到底部。
- TUI 单条用户消息按终端宽度换行后超过 8 行默认折叠；普通与简洁模式均支持点击末尾切换。搜索命中用户消息自动展开，原始会话、模型输入及时间记录不截断。
- Web 问题卡片使用单列、完整换行的选项；单选点整行提交，多选保留显式提交，其他回答支持输入后回车。侧栏只显示提醒与「前往处理」，定位并聚焦聊天区唯一的完整卡片。
- 提交期间禁止重复操作；失败保留草稿并显示错误。问题与审批继续使用服务端会话归属校验，无会话归属的可见任务保留处理入口。
- Rust 工作区、内部依赖、Web、npm 安装清单统一为 `0.131.0-rc1`；服务端现有 `X-App-Version` 继续从工作区版本派生。

- Web：`UserMessage`、`RuntimeHumanGates`、`RuntimeSidebar` 共 13 项通过；`yarn build`、`yarn lint` 通过。构建仍有大包提示。
- TUI 全部回归初跑 346 通过、2 个手动性能测试忽略；唯一失败是沙箱禁止本机端口监听，单独在允许监听的环境重跑通过。
