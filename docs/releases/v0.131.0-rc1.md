# v0.131.0-rc1

## 变更

- Web 单条用户消息超过约 12 行显示高度时默认折叠，点击「显示更多 / 收起」切换；调整窗口宽度后重新判断。全文留在原消息中，附件入口独立显示，展开不会继续跟随新回复滚到底部。
- TUI 单条用户消息按终端宽度换行后超过 8 行默认折叠；普通与简洁模式均支持点击末尾切换。搜索命中用户消息自动展开，原始会话、模型输入及时间记录不截断。
- Web 问题卡片使用单列、完整换行的选项；单选点整行提交，多选保留显式提交，其他回答支持输入后回车。侧栏只显示提醒与「前往处理」，定位并聚焦聊天区唯一的完整卡片。
- Runtime 活动面板改为整行折叠开关与指标磁贴；展开后按组排列并限制在面板内滚动，新建只读子 Agent 收进可展开入口，不再挤压会话列表。
- 提交期间禁止重复操作；失败保留草稿并显示错误。问题与审批继续使用服务端会话归属校验，无会话归属的可见任务保留处理入口。
- Rust 工作区、内部依赖、Web、npm 安装清单统一为 `0.131.0-rc1`；服务端现有 `X-App-Version` 继续从工作区版本派生。

## 验证

- Web：`UserMessage`、`RuntimeHumanGates`、`RuntimeSidebar` 共 14 项通过；`yarn build`、`yarn lint` 通过。构建仍有大包提示。
- 浏览器夹具在 390 像素与桌面宽度、深浅两套主题下检查 Runtime 活动展开/收起、面板内滚动、指标磁贴与新建表单，无横向溢出。
- Web 全量 vitest 仍有 1 项历史用例失败：`ProviderSetup` 期待已移除的旧插件审批文案，与 0.131 改动无关；CI 的 Web 检查为 build 与 lint，不包含该用例。
- TUI 全部回归 348 通过、2 个手动性能测试忽略；历史折叠专项覆盖中英文换行、重复正文独立展开、原文保留、归档/隐藏思考的行号映射、搜索展开，以及普通/简洁布局真实绘制后的鼠标点击。
- Rust 内部依赖版本一致性测试、`cargo fmt --all -- --check` 与 `git diff --check` 通过。
- 浏览器使用隔离的本地 Runtime 夹具，没有连接真实会话或模型。1440 像素桌面宽度下四项各占一行，长选项自动增高；390 像素窄屏页面与选项均无横向溢出。
- 浏览器验证「前往处理」聚焦正确问题卡片、长消息展开后原文末尾完整、自定义回答回车后以正确的会话与工作区到达夹具后端一次。

## 兼容边界

本版只改变客户端显示与侧栏操作入口；会话存储、模型输入、Runtime 审批协议和工具权限不变。Web 折叠状态只存在页面内，TUI 的展开状态不写入会话。
