# v0.134.0-rc4

本版只补 npm 包的说明页，程序行为不变。

## 修复

- `@niuwoai/willdeep` 在 npmjs 上每个版本都显示 "This package does not have a README"：`npm/willdeep/` 里没有 README，`package.json` 的 `files` 也没列它，发布时带不出去。现在包内放一份 README，写明安装、支持的平台和三种界面的起步用法，`files` 把它列入发布内容。
- 安装器不变：仍按包版本下载对应的 GitHub Release，校验 SHA256，确认包内只有预期的可执行文件，再写入 npm 的 bin 目录。
