# v0.133.0-rc5

本版只补 TUI 压缩期间的一行状态。

## 变更

- 压缩发生在「轮次开始」之后、正文之前，长则数十秒，期间聊天区没有任何新行，用户看着自己刚发的那句会以为卡住了。现在那句正下方挂一行「正在压缩上下文」，后面跟着已耗时，每秒刷新。
- 压缩完成时同一行整行换成「上下文已压缩」，不再读秒，也不再追加一行。
- 正文、思维链、工具调用或计划卡片任一出现，这一行就整行撤掉。轮次中断、结束或切换会话时同样撤掉，不留残留。
- 这行只在聊天区最后一条是用户消息时显示，只回答「我刚发的那句怎么没反应」。它不进记录，重开会话不会留下；活动区原有的压缩进度照旧保留，包括丢弃消息的条数。

CLI、Runtime SDK、内嵌 Web、npm 清单统一为 `0.133.0-rc5`；服务端继续通过现有 `X-App-Version` 与健康接口暴露版本。
