# v0.139.0-rc7

## Fixed

- 首屏只保留小鲸鱼、产品名、版本和欢迎语；会话 id 与续接命令继续在退出时打印。
- 完整与简洁布局的输入建议统一显示「（按 Tab 键采用）」，并用终端 DIM 降低文字亮度；按 Tab 只填入建议正文。
- 拆分聊天区选区模块，修复 `app_state.rs` 超过 3000 行导致的发布检查失败。rc6 未发布 GitHub Release 或 npm 包，rc7 包含其全部改动。
- 主模型每次请求前接收最新实例名；例如改名为“小滚”后，下一轮即可使用该称呼，WillDeep 产品身份保持不变。显示名以 JSON 数据传递，不作为指令或权限。

## Changed

- 定时任务管理用横向标签替代状态下拉框，各状态显示任务数量；任务总数包括保留的删除任务历史。

## 包含 rc6 改动

- Web 新会话可在首条消息前选择模型与审批档位，所选参数在首轮提交前生效；默认模型直接显示在模型按钮上。
- 修复简洁 TUI 拖选的行坐标偏移并显示选区高亮，拖动过程中不会触发展开或收起消息。
- 实例名支持中文、日文，保留宽度与不可见字符校验。
- Responses 失败时保留网关给出的错误码与说明，便于排查模型协议或参数问题。

## 内置插件

- willdeep-config 0.6.0-rc5。
