# CLI 与 TUI 产品模块

> 范围：命令行自动化、终端交互、输入与显示、历史、附件和本机诊断入口。开发版本见[产品概览](../../PRODUCT_OVERVIEW.md)；命令参数与完整快捷键由既有指南维护。

## 能力概要与用户入口

`willdeep` 提供多轮终端对话；`willdeep run` 提供自动化入口，默认经持久 Runtime 执行，支持 Prompt/stdin、文本和图片附件、Session 续接、断开后继续、text/JSON/NDJSON、静默模式与稳定退出码。`--local` 和 TUI `/local` 是显式进程内兼容入口；普通 TUI 输入与 `/runtime` 提交同一持久 Session/Turn。

## 已实现范围

### 启动与恢复

- 裸启动默认询问是否继续当前工作区最近的非空 Rust 会话，5 秒无操作后继续；键鼠操作暂停倒计时，无历史则新建。启动策略可保存为 `ask/latest/new`，单次覆盖及显式 resume 见[CLI 参考](../CLI_REFERENCE.md)。恢复读取现有记录并连接 Runtime，不重发旧输入或执行工具。
- 已有配置或环境凭据可以直接启动。没有可用 Provider 的交互首启打开内置 Web 快速配置，保存后继续 TUI；无需启用配置插件，Ruby 需求与终端手动配置见[首次使用](../FIRST_USE_SETUP.md)。some.im 浏览器登录保留。
- 空白会话显示鲸鱼、产品名、版本和问候，退出时提供会话 ID 与续接命令。`willdeep web`、`willdeep qr`、`/webapp` 提供相关入口；Runtime 托管开关和前台 Web 模式分别按[Runtime 模块](runtime-sessions.md)管理。
- 只读 CLI 查询只连接已有 Runtime，失败返回错误，不自动启动、重启或清理状态；TUI 检测到 Runtime 不可用时每次尝试启动一次，`/version` 保留失败原因与恢复命令。
- Bash/Zsh/Fish/PowerShell 补全和 roff man page 来自同一 Clap 命令树。安装平台包含 macOS Universal、Windows x64、Linux AMD64/ARM64，构建与发布入口见[安装指南](../INSTALL.md)。

### 输入、附件与待发消息

- Unicode 多行编辑统一换行、滚动、鼠标定位和光标规则；F2 展开大输入空间。支持文本粘贴附件和可删除图片，图片可从系统剪贴板附加；终端能否上报 Cmd+V 等组合键以指南为准。
- F3 或 `/attachments` 管理草稿附件且保留正文；`/attachments sent` 只读查看已发附件并可引用为新草稿；Ctrl+Q 待发列表可管理所选消息附件。支持预览、文本编辑、排序与删除。
- 空输入框按 ↑ 显示当前会话最近 100 条去重历史输入；上下选择、Enter/Tab 回填，回填后可编辑并手动发送，Esc 关闭；有草稿时仍按光标导航。
- 下一句建议在空输入框以灰字及 Tab 提示显示；Tab 只填入正文、不发送，打字隐藏、删空后恢复。提交使旧预测失效，回复收尾与晚到预测都不改写草稿。
- 运行中可立即执行帮助、清屏、侧栏、样式、技能及历史查看等本机命令；提示词与附件由默认 Runtime 队列接收。活动区显示待发条数，Ctrl+Q 或 `/queue` 可编辑、删除及立即发送；空闲时 Cmd+Enter 也能主动入队暂缓。
- **Runtime 已提交队列与显式本地队列分开。** Runtime 队列跨 Web/TUI/手机共享，退出终端不丢已接受消息；管理面板不暂停 Runtime 调度，已启动项拒绝过期编辑。显式本地执行仍保留本地插话和面板暂停自动发送语义，送达插话不可撤回。早期“队列只在 TUI 进程内”“打开面板一律暂停”的描述不适用于默认 Runtime；权威状态见[持久队列](runtime-sessions.md#持久队列与人工等待)。
- 消息成功启动下一轮时原文放到上一轮结束线之后，重复用户消息各自回显，发送失败保留待发状态；人工等待期间普通输入不被当作原问题答案。

### 聊天与状态显示

- `[ui].mode` 支持 `full`（默认）与 `compact`；`/uistyle` 即时切换，`status/no-status` 独立控制简洁状态栏，不改配置文件。简洁模式用细线分开正文与输入，保留侧栏、弹窗、附件、搜索与队列；输入/运行时背景稳定，空闲等待可低频呼吸。
- 默认简洁回复以计划卡和一行可替换的阶段状态汇报过程，收尾落正文；`/verbose` 与 `/short` 切换回复风格。Thought 用耗时摘要折叠，按需展开；连续思考只保留最后一条显示，已展开项保留，原始记录不删除。
- 工具调用默认只显示最近一批的收起摘要，`/tools` 可展开；命令行可点击查看完整命令。历史 UI 演变中的多条工具尾巴和固定思考末三行不再并列当作现行显示规则。
- 用户长消息按终端换行预览 8 行，可展开/收起；长历史采用归档渲染窗口，顶部按需加载，记录本身不截断。已完成历史复用排版，增量只绘制可见区域。
- 支持常用 Markdown、HTML 换行、按中文显示宽度排版的 GFM 表格。Markdown 图片为媒体卡，Ctrl+L 汇总链接和图片；系统浏览器打开不经 Shell，图片仅显式安全加载，在终端原生协议与 Unicode 半块字符间降级。
- 聊天支持内建拖选和高亮、复制与 Markdown 引用，修正简洁模式落点；Ctrl+S 另有选择入口。快捷键与终端捕获的具体差异见[TUI 指南](../TUI_GUIDE.md)。
- 聊天保留用户原文、正式回复、必要错误和可展开过程投影，提交 ID、轮次确认、排队与任务状态进入状态层。消息时间独立保存、不进模型上下文，旧消息无时间不补造；模型名随会话展示。
- 轮次结束分隔线紧贴上一轮，“轮到你”仅在最后一条显示；结束且无待发时响铃一次，不重复提示。输出生成时连按两次 Esc 才中断，单次先处理弹层；旧单次 Esc 与具体毫秒窗口差异不在本页重订契约。
- 首答耗时在首个非空正文增量到达时记录，包含本次提交入口之后的准备、提交请求、排队、传输与思考等待；完整正文、用量及无用量纯工具响应的调用开始事件保留兜底。Runtime 按提交事件头及 Turn/Task 身份排除旧/异属输出，重连恢复不创建首答；正文到 usage 的后续生成不再计入首答，它不是纯模型 prefill 耗时。
- 中英日界面、语言偏好、角色配色、用量/缓存/耗时与焦点提示均可见。全局快捷键帮助、Ctrl+P 命令面板、四区焦点、聊天搜索和鼠标操作覆盖主要交互。

### 会话、工作区与运行面板

- `/history`、Ctrl+R、`/session search` 共用历史会话面板，支持标题/正文组合搜索与过滤、命中摘要、键盘/鼠标原地切换；已归档会话先恢复，切换前保存草稿与会话状态。
- `/new` 或 `/session new` 新建独立历史，沿用当前 Provider/模型/配置并从当前事件头读取；`/clear` 只清显示。`/workspace` 原地切换注册工作区并保存/恢复专属 Session、事件游标与技能视图，不取消旧工作区后台任务；跨工作区后旧绑定 `/local` 保守禁用。
- `/model` 提供 Provider/模型两栏（窄屏两步）、分栏搜索、翻页、鼠标与 F5 刷新；浏览不应用，确认后才切换，运行中延后至轮末。直接模型名和手动输入可用，继承关系归[工具与模型](tools-models.md)。
- Attention Inbox 聚合待处理、工作中与最近完成项，支持详情、停止、重试、已读持久化和审批/问答定位。Agent 详情按需读受保护工具时间线、报告与 Diff，操作不覆盖 Composer 草稿。
- `/diff` 及 Diff Inbox 提供文件导航、Unified/Side-by-side、Combined/Staged/Unstaged、搜索、审查与 Commit Preview；模态独占键鼠、终端控制字符转义，关闭后重绘。决定、验证和撤销的安全语义归[安全与验证](security-verification.md)。
- 顶层 `session list/get/turns/stop` 查询或精确停止活动 Turn；完整子会话使用 `session child` 与 TUI `/session children`（支持 `--fork`、`--worktree`、`--snapshot`、`--model`），工作流使用 `/workflow`，见[智能体与协作](agents-collaboration.md)。

## 当前限制与诊断

`willdeep doctor [--json] [--bundle PATH]` 不联系 Provider，可生成本机就绪诊断与私有脱敏包；这不证明远端认证或模型能力。模型响应流超时不自动重放，状态复位不表示成功，需检查已有改动后续做。新版检查在空闲时提示、共享缓存且可关闭，不自动安装，也不发送工作区/会话或模型凭据。

部分旧指南仍保留本地队列、单栏模型选择、终端选择和旧交互参数。本页只统一产品边界，最新实际快捷键须结合当前实现；不将历史差异默认为新功能。
