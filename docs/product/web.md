# Web 产品模块

> 范围：浏览器中的聊天、项目与会话导航、输入区、配置工作台及活动面板。开发版本与维护约定见[产品概览](../../PRODUCT_OVERVIEW.md)。本页记录能力和限制，操作与参数以所链接的专题文档为准。

## 能力概要与用户入口

内嵌 Web 服务提供多工作区聊天、SSE 进度、会话管理和运行状态。通过 `willdeep web` 或 TUI `/webapp` 打开；显式前台 Web、首次配置引导与 Runtime 托管服务的生命周期分别见[首次使用](../FIRST_USE_SETUP.md)和[Runtime Daemon](../RUNTIME_DAEMON.md)。

## 已实现范围

### 项目与会话导航

- 侧栏按项目展示会话树；默认最近 5 条，「显示更多」增加 10 条，「收起」回到 5 条，每项目最多列 20 条。按最近更新排序，搜索按标题跨项目查找，未生成标题时匹配侧栏显示的首条消息。
- 会话列表、重命名、指定已完成 Turn 分叉、归档/恢复、精确确认删除和显式导出共用 Runtime API。空白会话不进入历史列表；分叉保留来源，来源不在当前列表时仍能独立访问。
- 完整子会话按父关系展示，可以打开独立聊天及返回父会话；父聊天运行时通过新页面保留原聊天流和草稿。任务区可选择全新/继承已完成历史、共享只读/独立工作树、HEAD/冻结基线及可选模型，查看状态和报告，具体限制见[智能体与协作](agents-collaboration.md)。
- 一级导航尺寸与样式统一，条目独立滚动；配置与插件为并列一级入口，智能体及 RSI 使用同一导航布局。

### 聊天与输入区

- 宽正文画布支持窄屏、深浅主题和简中/英/日界面。聊天独立滚动；长会话只排版最近部分，顶部按需恢复更早轮次，原始记录不截断。
- 默认简洁显示：执行中保留一行可替换的工作状态与耗时，收尾后落为正文。思考显示耗时并可按需展开；历史轮次默认隐藏思考、折叠工具。连续工具调用聚合摘要，展开查看全部详情，详情多行与滚动不会挤占相邻行。旧版思维尾巴和工具折叠演变保留在[历史快照](history/overview-through-0.142.0-rc1.md)。
- 单条用户长消息预览约 12 行，可展开/收起，支持键盘操作和窄屏重排；仅改变显示，不改变发送、存储和原文。代码块有复制与成功/失败反馈。
- 支持文本/图片粘贴附件、发送前删除、紧凑缩略图、排序、图片大图及文本编辑；已发送附件只读，可引用回草稿。已提交队列与本机草稿分开，见[Runtime 队列](runtime-sessions.md#持久队列与人工等待)。
- `/` 命令、`$` 技能与 `@` 引用支持搜索、光标定位、键盘及鼠标选择；`@` 列出 MCP 服务、启用兼容的智能体和工作区文件，选择只插入引用，中文/空格路径自动引用，邮箱不误触发。技能发现包含已配置额外根目录并遵守工作区允许列表。
- 轮次结束后的下一句预测只在空输入框显示，Tab 只填入不发送，打字时隐藏、删空后恢复；晚到结果按世代丢弃，不改草稿。预测调用与开关归[工具与模型](tools-models.md)。
- 模型、权限与目标控件位于输入框下方。新会话首条消息前即可预选 Provider/模型和审批档位，先保存草稿，首条提交时校验并写入 Session/Runtime；模型选择按 Provider 加载目录并支持搜索，未选择时显示实际默认模型。
- 待回答问题统一在聊天区操作：选项整行可点，可提交其他回答；多选需确认后提交，侧栏只提醒和定位。审批「允许一次」与「拒绝」有明确主次样式。

### 配置与管理

- 主包内置 Provider 快速设置及完整配置工作台：配置快照/schema、变更预览/应用、校验、备份恢复、模板、模型目录及 Provider/MCP/子代理集合管理。不要求安装或启用配置插件；快速设置由 Rust 提供，完整工作台部分功能需要 Ruby，见[首次使用](../FIRST_USE_SETUP.md)。
- 全局默认模型写回所选默认 Provider；可设置上下文窗口、最大输出 Token、预算、子代理轮次及实例名。模型可选目录项或手动填写；错误保留服务原因和 HTTP 状态，识别代理登录页及无效响应。
- 技能与规则管理提供发现、查看、编辑、创建、删除、排序、启停及 GitHub 安装入口；规则与 Provider 解析归[工具与模型](tools-models.md)。配置与密钥展示仍走脱敏边界。
- 公网入口管理页管理监听、`public_url`、站点/表单/Webhook、目录选择和失败投递，提供联邦标签；协议、分享访客权限与手机入口归[集成模块](integrations.md)。
- 协作与定时任务从标题栏按需展开，收起保留草稿；定时任务用含数量的状态标签，加载未完成时不展示不完整计数。智能体库与实验工作台分别见[协作](agents-collaboration.md)和[评测与 RSI](evaluation-rsi.md)。

### 活动、失败与重连

- 活动面板按工作区展示 Agent、后台 Task、待审批/回答、关注项和 Tool/Artifact 摘要；持续刷新，按公开身份读取工具时间线、状态、耗时与 Diff Artifact。
- 可处理审批、单选/多选/自定义回答，并控制后台 Worker 的停止、重试、指定模型重试和补充指令；公开只读派工入口及安全边界见[智能体与协作](agents-collaboration.md)。聊天 SSE 不锁住人工操作。
- Web/TUI 共用持久 Session/Turn。刷新或普通断网后按持久游标重新附着同一 Turn、去重事件，不重复提交 Prompt；断线期间已结束时读取最终 Turn 与 Core 消息。停止始终指向具体 Turn。
- `turn.failed` 显示本地化原因与类别；展开详情才请求本机诊断，校验回环监听、会话工作区和任务归属，并脱敏凭据。上游 `response.failed` 保留有界错误码与原因。

## 当前限制

- Web 工作区只取 Runtime 注册表与启动白名单的交集。模型/审批切换与 intake 管理配置仅在回环监听开放；完整子会话（含 worktree 子会话）不开放公共分享，worktree 子会话的工作区通过父会话授权。权限与公共数据投影以[安全与验证](security-verification.md)为准。
- 公共活动摘要与受保护的本机诊断分开，不将 Prompt、工具载荷、报告正文、内部路径或错误直接混入公开 DTO；查看活动不表示结果已经验收。
- [Web 使用指南](../WEB_GUIDE.md)部分旧段落仍描述工作区下拉框和 `/webapp` 子进程。项目树采用本页所述较新能力，托管生命周期以 Runtime 专题为准；本次拆分不重写整份操作指南。
